## Use case

The vulnerability exists in a feature that allows users to generate product image previews by providing a URL, which can be exploited to perform Server-Side Request Forgery (SSRF) attacks against internal services.

## Steps to test

1. Identify the endpoint for generating image previews, e.g., POST /api/v1/preview-image.
2. Send a request with a payload that includes a URL pointing to a local or internal service, such as {'image_url': 'http://127.0.0.1:8080/admin'}.
3. Observe the response to determine if the request was blocked or if the internal service was accessed.
4. Iterate with different internal IP addresses or services until a valid response is received.
