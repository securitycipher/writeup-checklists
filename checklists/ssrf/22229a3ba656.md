## Use case

The application allows users to upload files via URLs, which can be exploited to perform SSRF attacks. This is critical as it may lead to unauthorized access to internal services or sensitive data.

## Steps to test

1. Identify a feature that accepts a URL input for file uploads.
2. Use Burp Suite to intercept the request and modify the URL to your listener (e.g., http://yourlistener.com).
3. Trigger the file upload feature and check your listener for incoming requests.
4. If successful, replace the listener URL with internal IP addresses (e.g., http://127.0.0.1) to probe internal services.
5. Monitor the application behavior for any changes or responses indicating access to internal resources.
