## Use case

The Coin98 Browser Extension was vulnerable to provider hijacking due to unvalidated localStorage manipulation, allowing attackers to redirect transactions and intercept dApp requests without user interaction. This flaw could lead to account takeover and significant financial loss.

## Steps to test

1. Visit an arbitrary website that can execute JavaScript.
2. Inject malicious JavaScript to write engineered parameters into localStorage before the Coin98 extension initializes.
3. Ensure the injected parameters are designed to manipulate the state keys used by the Coin98 content script.
4. Trigger the Coin98 extension to load and observe if window.ethereum or window.coin98 is overwritten with the rogue provider.

## Commands

```text
localStorage.setItem('key', 'malicious_value');
window.location.reload();
[ Unprivileged Web Page ]
│
├─► Poison localStorage keys
│
[ Coin98 Content Script ]
│
├─► Reads unvalidated state from localStorage
├─► Evaluates dynamic script injection parameters
│
[ Window DOM Context ]
└─► Overwrites window.ethereum / window.coin98 with Rogue Provider
```
