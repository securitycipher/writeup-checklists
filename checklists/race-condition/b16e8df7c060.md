## Use case

The coupon validation endpoint on foto.kruidvat.nl was vulnerable to a race condition, allowing an attacker to apply the same promotional coupon multiple times by sending concurrent requests, leading to potential financial loss.

## Steps to test

1. Perform subdomain enumeration using 'subfinder -d kruidvat.nl -silent | httpx -status-code -title | tee kruidvat-subs.txt'.
2. Identify the coupon validation endpoint: POST /carts/validate-voucher_submit/.
3. Intercept a valid coupon request in Burp Suite and modify the 'VoucherCode' parameter to a valid coupon (e.g., 28PRINT200).
4. Create a Python script to send 50 concurrent POST requests to the endpoint with the same 'VoucherCode'.
5. Analyze the responses to confirm if all requests are accepted without rejection.
