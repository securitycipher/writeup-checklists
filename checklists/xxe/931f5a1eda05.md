## Use case

The application processes XML input from various sources, including file uploads and APIs, which can be exploited to read sensitive files from the server due to improper handling of external entities.

## Steps to test

1. Identify potential XML entry points such as SOAP APIs or file upload functionalities.
2. Craft an XML payload that includes an external entity declaration, e.g., ENTITY xxe SYSTEM 'file:///etc/passwd'.
3. Submit the crafted XML payload to the identified entry point.
4. Observe the response to check if the contents of the targeted file are returned.

## Commands

```text
curl -X POST -H 'Content-Type: application/xml' -d '<!DOCTYPE foo [<!ENTITY xxe SYSTEM "file:///etc/passwd">]><foo>&xxe;</foo>' http://example.com/api/endpoint
ENTITY xxe SYSTEM "file:///etc/passwd
```
