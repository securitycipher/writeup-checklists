## Use case

The vulnerability was found in a file upload feature that accepted XML files, allowing an attacker to exploit XML External Entities to access sensitive files like /etc/passwd, which could lead to further attacks on the internal network.

## Steps to test

1. Identify a web application with a file upload feature that accepts .xml files.
2. Craft a malicious XML file that includes an external entity declaration pointing to a sensitive file, such as /etc/passwd.
3. Upload the crafted XML file through the file upload feature.
4. Observe the response from the application to check if it returns the contents of the sensitive file.

## Commands

```text
curl -X POST -F 'file=@malicious.xml' http://example.com/upload
```
