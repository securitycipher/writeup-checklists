## Use case

The vulnerability lies in AI applications where prompt injection can manipulate the model's output, leading to unintended actions or data exposure. This is critical as it can compromise the integrity of AI-driven features and applications.

## Steps to test

1. Identify an AI application that accepts user input for processing prompts.
2. Craft a prompt that includes malicious input designed to manipulate the AI's response.
3. Submit the crafted prompt through the application's input field.
4. Observe the output generated by the AI to determine if it reflects the injected prompt's influence.

## Commands

```text
POST https://example.com/api/ai/prompt
Content-Type: application/json
Body: {"prompt": "malicious input here"}
```
