## Use case

The vulnerability arises when a website links to a non-existent social media page, allowing an attacker to claim that page and impersonate the organization. This can lead to phishing, misinformation, and reputation damage.

## Steps to test

1. Visit the target website and locate the social media icons in the footer.
2. Click on the LinkedIn icon to check if the linked page exists.
3. If the page returns a 'not found' error, note the vanity URL.
4. Create a LinkedIn Company Page using the exact name of the target organization.
5. Claim the vanity URL associated with the organization.
6. Verify that the LinkedIn icon on the target website now points to your newly created page.
