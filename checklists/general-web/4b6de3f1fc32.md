## Use case

The application allowed users to input arbitrary URLs in profile fields without sufficient validation, enabling attackers to deliver malicious files through trusted profile links. This matters because it exploits the trust users place in profile links, potentially leading to malware delivery and social engineering attacks.

## Steps to test

1. Navigate to the profile customization feature of the application.
2. Input an arbitrary URL (e.g., https://attacker.example/malware.zip) in a profile link field.
3. Save the profile and view the public profile page.
4. Click the profile link displayed on the public profile.
5. Observe that the link directs to the attacker-controlled URL, initiating a file download.
