## Use case

The article discusses the possibility of downloading files using a POST request instead of the conventional GET request. This matters because it can lead to unexpected behavior in web applications that do not properly validate or restrict file downloads based on request methods.

## Steps to test

1. Identify the file download endpoint, typically something like '/download'.
2. Craft a POST request to the identified endpoint with the appropriate parameters in the request body.
3. Include headers such as 'Content-Type: application/x-www-form-urlencoded'.
4. Test with various parameters like 'file_id' and 'token' to see if the server responds with the requested file.

## Commands

```text
POST /download HTTP/1.1
Host: example.com
Content-Type: application/x-www-form-urlencoded
file_id=123&token=abc
http
GET /files/document.pdf HTTP/1.1
Host: example.com
GET /files/document.pdf HTTP/1.1
```
