## Use case

Malware can use DNS queries to communicate with a command and control server, allowing attackers to control compromised systems covertly. This is significant as it can bypass traditional security measures that monitor HTTP traffic.

## Steps to test

1. Identify the DNS server being used by the target system.
2. Monitor DNS queries from the target system using a tool like Wireshark.
3. Look for unusual DNS queries to domains that are not recognized or are known to be malicious.
4. Analyze the DNS responses for encoded or unusual data that may indicate command and control communication.

## Commands

```text
dig @<malicious_dns_server> <suspicious_domain>
nslookup <suspicious_domain>
tcpdump -i <interface> port 53
```
