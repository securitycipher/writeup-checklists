## Use case

Expired domains can be repurposed by attackers to redirect users to malicious sites, exploiting the trust associated with the domain's history. This can lead to phishing, malware distribution, and other forms of cybercrime.

## Steps to test

1. Identify expired domains using a domain registrar or monitoring tool.
2. Register the expired domain through a legitimate domain registration service.
3. Configure DNS records to point to a new hosting provider.
4. Set up redirects from the expired domain to a malicious site or payload.
5. Monitor traffic to the domain to profile visitors and adjust the redirect strategy.
