## Use case

The vulnerability allowed unauthenticated users to delete conversations created by other users due to a missing authentication check on the DELETE endpoint. This could lead to significant data loss and impact user privacy.

## Steps to test

1. Analyze the JavaScript bundle of the target application to identify API endpoints.
2. Send a POST request to /api/conversations without authentication to create a conversation.
3. Note the ID of the created conversation.
4. Open a new session and send a DELETE request to /api/conversations/{id} using the ID from step 3.
5. Verify the deletion by sending a GET request to /api/conversations/{id} to confirm it returns a 404 error.
