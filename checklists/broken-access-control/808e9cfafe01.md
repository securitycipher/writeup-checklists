## Use case

The application allowed users to download files based on a user-controlled file key, leading to unauthorized access to files belonging to other users. This misconfiguration allowed attackers to generate presigned URLs for files they should not have access to.

## Steps to test

1. Log in as a user with client ID 'client123'.
2. Attempt to download a file using a valid file key like 'client123_report.pdf'.
3. Observe the response and confirm the file is downloadable.
4. Now attempt to download a file using a manipulated file key like 'client123/../client999/private.pdf'.
5. Check if the server allows the request and generates a presigned URL for the unauthorized file.
