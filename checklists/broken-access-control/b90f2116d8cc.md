## Use case

The article discusses Broken Object Level Authorization (BOLA), a common API vulnerability where the API fails to verify if a user is authorized to access a specific object. This can lead to unauthorized access to sensitive data or actions.

## Steps to test

1. Create two test accounts with the same privilege level but different data ownership.
2. Log in as User A and capture a request containing one of A's object IDs.
3. Switch to User B's session or token.
4. Replay the exact same request with A's object ID.
5. Check if User B can access or modify User A's object.

## Commands

```text
GET /api/orders/1001
PUT /api/orders/1001

GET /api/users/1234
POST /api/messages { "recipient_id": 1234 }

Return it

}

1001 → 1002 → 1003
```
