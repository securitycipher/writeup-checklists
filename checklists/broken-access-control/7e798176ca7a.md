## Use case

The vulnerability allowed a regular workspace member to access another user's private request history and active API sessions due to missing authorization checks in the GraphQL API. This exposure of sensitive data could lead to unauthorized modifications and information disclosure.

## Steps to test

1. Authenticate as a regular user in the Hoppscotch application.
2. Use the GraphQL query to retrieve the Team object for your workspace using the teamID parameter.
3. Extract the TeamMember objects from the Team response.
4. For each TeamMember, access the nested User object using the user resolver.
5. Check the returned User object for fields like currentRESTSession and currentGQLSession.
6. Use the RESTHistory and GQLHistory fields to fetch another user's request history.
