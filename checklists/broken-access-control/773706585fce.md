## Use case

The DHL shipment API allowed unauthorized access to shipment information using a UUID without requiring authentication, leading to potential exposure of sensitive customer data.

## Steps to test

1. Create a shipment through the DHL shipment flow until the shipment document is generated.
2. Open Burp Suite and intercept the API request for the shipment: POST /api/shipment/READECTED HTTP/2 with Content-Type: application/json and body {"externalId":"<YOUR-SHIPMENT-UUID>"}.
3. Send the request with your own shipment UUID to retrieve the corresponding shipment data.
4. Replace the externalId with another valid shipment UUID: {"externalId":"<ANOTHER-SHIPMENT-UUID>"} and send the request again.
5. Remove any authentication cookies and session-related headers from the request.
6. Send the request again to observe if the API returns the shipment associated with the new UUID without requiring authentication.
