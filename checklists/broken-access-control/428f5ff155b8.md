## Use case

The unauthenticated WebSocket endpoint allowed any user to connect and receive sensitive live customer data, which could lead to significant privacy violations and data leaks.

## Steps to test

1. Identify the WebSocket endpoint by sending a GET request to /socket.io/?EIO=4&transport=websocket.
2. Establish a WebSocket connection using a library like websocket in Python.
3. Attempt to join the default namespace by sending a message with a guessed ID parameter.
4. Iterate through multiple IDs to find one that returns customer data.
