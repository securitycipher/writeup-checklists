## Use case

The vulnerability allowed any logged-in user to access the email addresses and phone numbers of all registered users due to a misconfiguration in the data replication process, which ignored the original access controls.

## Steps to test

1. Sign up for a free account on the platform.
2. Open the browser console.
3. Run the command: platform.data.query({ entity: 'ProfileEntity', select: ['displayName', 'email', 'phone'], count: true, limit: 5 }).
4. Observe the total number of profiles accessible and the returned email and phone data.
5. Verify the access control by querying a private profile from another account.
