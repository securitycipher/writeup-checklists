## Use case

Insecure Direct Object Reference (IDOR) vulnerabilities allow attackers to access unauthorized data by manipulating user IDs or other identifiers in requests. This can lead to unauthorized data exposure and privacy violations.

## Steps to test

1. Identify endpoints that accept user IDs or other identifiers in requests.
2. Change the user ID in the request to another valid ID and observe the response.
3. Check if the response reveals data belonging to the user associated with the new ID.
4. Document any unauthorized access to data and the specific requests made.

## Commands

```text
GET https://example.com/api/user?id=1
GET https://example.com/api/user?id=2
```
