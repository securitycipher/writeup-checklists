## Use case

The web application relied on client-side authorization, allowing a standard user to escalate privileges to an administrator by manipulating the permission matrix returned by the server. This vulnerability is critical as it exposes sensitive data and administrative functionalities to unauthorized users.

## Steps to test

1. Step 1: Login as a standard user to app.target.com using a low-privileged test account.
2. Step 2: Intercept the HTTP response from the /user/self endpoint using an intercepting proxy.
3. Step 3: Modify the permissions in the response body to grant administrative access (e.g., change 'is_admin': false to true).
4. Step 4: Access the /admin/users endpoint to retrieve sensitive administrative data.
