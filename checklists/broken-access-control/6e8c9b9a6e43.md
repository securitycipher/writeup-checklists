## Use case

The vulnerability was in the time tracking approval process where an attacker could manipulate the employeeId and timesheetId parameters to approve time tracking records they were not authorized to access, risking financial integrity.

## Steps to test

1. Identify the endpoint for approving time tracking records: POST /time/v1/tracking/validation/approve.
2. Capture a valid request to this endpoint using a legitimate employeeId and timesheetId.
3. Modify the employeeId and timesheetId in the request to those of another employee.
4. Send the modified request and observe if the approval is granted without proper authorization.

## Commands

```text
POST https://api.examfit.com/time/v1/tracking/validation/approve
Content-Type: application/json
Body: {"employeeId": "<attacker_employee_id>", "timesheetId": "<attacker_timesheet_id>"}
```
