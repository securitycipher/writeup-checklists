## Use case

The vulnerability allowed an attacker to access and delete victim data by manipulating parameters in the request. This is critical as it exposes sensitive information and can lead to unauthorized data deletion.

## Steps to test

1. Identify the endpoint used for data retrieval and deletion, e.g., 'https://ads.google.com/_/GhsUi/data/batchexecute?'
2. Capture a valid request using a tool like curl or Postman to see the parameters being sent.
3. Change the 'cid' and 'bid' parameters to those of a victim's data you want to access or delete.
4. Send the modified request and observe the response for any sensitive data or confirmation of deletion.
5. Attempt to set the 'f.req' parameter values to 'null' for specific employee IDs to test if you can delete their data.
