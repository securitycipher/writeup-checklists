## Use case

A free-tier user was able to enumerate and execute internal production workflows due to a missing authorization check, allowing access to sensitive internal configurations and execution capabilities.

## Steps to test

1. Create a fresh free account on the target platform.
2. Send a GET request to /api/.../workflows to confirm no workflows are owned.
3. Send a GET request to /api/.../workflows/registrations to enumerate internal workflows.
4. Identify internal workflow names indicating they are not for customers.
5. Send a POST request to /api/.../workflows/registrations/<REDACTED_ID>/execute with a valid execution payload.
6. Observe the response confirming execution under your user ID.
