## Use case

The application allows unauthorized access to an admin panel due to a lack of proper access control checks. This vulnerability can lead to unauthorized actions such as deleting user accounts.

## Steps to test

1. Open the lab and explore the application as a normal user.
2. Check the robots.txt file for hidden paths.
3. Access the admin panel directly by appending the discovered path to the base URL.
4. Perform actions like deleting a user account without any authentication or authorization checks.
