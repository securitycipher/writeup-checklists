## Use case

The telecom company's account management feature allowed unauthorized access to sensitive user information by manipulating response values. This vulnerability could lead to full account takeover and exposure of personal identifiable information (PII).

## Steps to test

1. Log in to the telecom account management system with valid credentials.
2. Capture the request and response using a proxy tool like Burp Suite.
3. Identify the response structure and note the parameters returned, especially those containing user identifiers.
4. Modify the user identifier in the request to a different user's identifier and resend the request.
5. Observe the response for unauthorized access to another user's account details.
6. Attempt to manipulate the OTP or password response values to bypass authentication.

## Commands

```text
GET https://example.com/account?user_id=12345
GET https://example.com/account?user_id=67890
POST https://example.com/login -d 'username=user&password=pass&otp=random'
POST https://example.com/login -d 'username=user&password=pass&otp=valid_otp'
```
