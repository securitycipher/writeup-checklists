## Use case

The application improperly validates JWT tokens, allowing an attacker to forge tokens and bypass authentication, leading to unauthorized access to sensitive partner records.

## Steps to test

1. Send a GET request to /api/partner without a token and note the 500 validation error.
2. Construct a JWT with the header set to {'alg': 'none', 'typ': 'JWT'} and a payload containing a valid user ID.
3. Send the forged token in the Authorization header as 'Bearer <your_token>' with a GET request to /api/partner?id=<valid_id>.
4. Observe that the server responds with a 200 status and the corresponding partner record.
5. Test with different IDs in the query parameter while using the same forged token to enumerate records.
