## Use case

The vulnerability existed in a SaaS platform where a low-privilege user account could access sensitive personal information of all users due to a misconfigured database policy that allowed excessive data visibility.

## Steps to test

1. Sign up for a free account on the target SaaS platform.
2. Authenticate using the email/password or Google OAuth.
3. Capture the API request made to fetch user data after logging in.
4. Analyze the API response to verify if it returns PII of all users instead of just the authenticated user.

## Commands

```text
GET https://example.com/api/users
Authorization: Bearer {JWT_TOKEN}
```
