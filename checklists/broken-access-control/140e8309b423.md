## Use case

The vulnerability allows an attacker to exploit an Insecure Direct Object Reference (IDOR) in the partner profile user adding endpoint, enabling them to escalate privileges and gain admin access to a victim's project.

## Steps to test

1. Create two separate user accounts: a 'Victim' user and an 'Attacker'.
2. Create a new project under both accounts.
3. Add a partner profile to the project using the profile ID.
4. From the Victim's account, initiate the process of adding a normal user to the partner ID.
5. Intercept the resulting POST request and analyze the data payload.
6. Acquire the Victim's EngagementId from the intercepted request.
