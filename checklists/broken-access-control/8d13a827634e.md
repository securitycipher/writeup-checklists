## Use case

The application allows users to access invoices without verifying ownership, leading to unauthorized data exposure. This vulnerability matters because it can lead to sensitive information being accessed by unauthorized users.

## Steps to test

1. Step 1: Sign up and create two accounts, Account A and Account B.
2. Step 2: Log in as Account B and capture the request for an invoice using Burp Suite.
3. Step 3: Modify the request to change the invoice ID to one belonging to Account A.
4. Step 4: Send the modified request and observe the response for any invoice data.
