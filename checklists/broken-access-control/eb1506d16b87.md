## Use case

The invitation management system allowed a lower-privileged Manager role to downgrade an Organization Owner role through invitation synchronization across two applications, leading to unauthorized privilege escalation.

## Steps to test

1. Link both applications (app.redacted.com and tasks.redacted.com) as an Organization Owner.
2. Remove the second Owner from tasks.redacted.com, leaving the user as an Owner in app.redacted.com.
3. Log in as a Manager in tasks.redacted.com.
4. Invite the existing Owner as a User to the organization.
5. Have the invited Owner accept the invitation and observe the role change.

## Commands

```text
POST /invite HTTP/1.1
Host: tasks.redacted.com
Content-Type: application/json
Authorization: Bearer <manager_token>
{ "email": "existing_owner@example.com", "role": "user" }
```
