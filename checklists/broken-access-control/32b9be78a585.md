## Use case

The file upload and address delivery functionalities were tested for vulnerabilities. These features are critical as they can lead to Remote Code Execution (RCE) and Insecure Direct Object Reference (IDOR) vulnerabilities, respectively.

## Steps to test

1. Navigate to the profile file upload feature.
2. Attempt to upload a file with a malicious payload (e.g., a web shell).
3. Check the response for any indication of successful upload or execution.
4. Next, access the delivery address feature and identify the parameter used for the address ID.
5. Manipulate the address ID parameter to access another user's address (e.g., change 'addressId=123' to 'addressId=124').
6. Observe the response to determine if unauthorized access is granted.
