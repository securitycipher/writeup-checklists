## Use case

The Revive Adserver 6.0.7 XML-RPC API allows a non-admin user to exploit a session leak and perform unauthorized actions across different agencies, compromising the integrity of ad campaigns and billing.

## Steps to test

1. Attempt to log in to the XML-RPC service using non-admin credentials via POST /www/api/v1/xmlrpc/LogonXmlRpcService.php with the appropriate XML payload.
2. Capture the Set-Cookie header from the response to obtain the sessionID.
3. Use the leaked sessionID to call ZoneService.linkCampaign() via POST /www/api/v1/xmlrpc/ZoneXmlRpcService.php with the zoneId and campaignId parameters.
4. Verify the unauthorized association by querying the database for the placement_zone_assoc_id using the provided SQL query.
