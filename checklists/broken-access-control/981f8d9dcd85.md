## Use case

The Salesforce application allowed unauthenticated guest users to access sensitive customer data, including invoice documents and personally identifiable information (PII), due to misconfigured permissions. This exposure could lead to significant privacy and security risks for customers.

## Steps to test

1. Access the Salesforce application as a guest user.
2. Fill out the form to request an invoice, capturing the aura.token from the request.
3. Use the token to make a request to the endpoint for the Contact object: /services/data/vXX.X/sobjects/Contact.
4. Analyze the response to retrieve customer information without authentication.
5. Identify document-related objects by making a similar request for the DOCUMENT entity.
6. Download invoices using the identified document IDs via /servlet/servlet.FileDownload?file=ID.
