## Use case

The article discusses various functionalities of web applications that can be tested for vulnerabilities, emphasizing the importance of thinking like a pentester. For example, manipulating parameters in the registration process can lead to privilege-related testing and potential unauthorized access.

## Steps to test

1. Navigate to the registration page.
2. Modify the 'role' parameter in the request body to 'role=admin'.
3. Submit the registration form.
4. Check if the account is created with admin privileges.

## Commands

```text
POST /register HTTP/1.1
Host: example.com
Content-Type: application/json
Content-Length: [length]
{"username":"testuser","password":"testpass","role":"admin"}
role=user
/download?id=123
```
