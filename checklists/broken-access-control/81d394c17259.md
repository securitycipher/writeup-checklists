## Use case

The auto-save feature of a document management platform allowed unauthorized access to confidential documents due to a Blind Cross-Tenant Authorization Bypass, which could lead to significant data leaks.

## Steps to test

1. Identify the WebSocket endpoint used for the auto-save feature in the document editor.
2. Establish a WebSocket connection to the endpoint while logged in as a regular user.
3. Monitor the WebSocket messages for document updates or changes.
4. Attempt to modify the document ID parameter in the WebSocket message to access documents belonging to other users.
5. Observe if the application returns sensitive data from other users' documents.

## Commands

```text
ws://example.com/autosave?user_id=YOUR_USER_ID&document_id=TARGET_DOCUMENT_ID
```
