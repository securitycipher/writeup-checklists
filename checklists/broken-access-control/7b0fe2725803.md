## Use case

The newsletter page allowed unauthorized users to create posts by manipulating the 'category_cd_third' parameter in the post request. This vulnerability could lead to the creation of empty posts on a restricted page, potentially disrupting the content for legitimate users.

## Steps to test

1. Intercept the request for uploading a post using a tool like Burp Suite.
2. Identify the 'category_cd_third' parameter in the request body.
3. Change the value of 'category_cd_third' to a different section code (e.g., T101005).
4. Send the modified request and observe if the post is uploaded successfully.
5. Repeat the process with various values for 'category_cd_third' to confirm access to different sections.
6. Check the URL parameter 'l' to verify the section where the post was uploaded.

## Commands

```text
POST https://example.com/upload_post HTTP/1.1
Content-Type: application/x-www-form-urlencoded
category_cd_third=T101005&content=YourPostContent
```
