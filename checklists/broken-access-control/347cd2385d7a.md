## Use case

The API endpoint allows a logged-in user to dismiss a notification tied to another user's account due to a lack of authorization checks on the customerId parameter, which could lead to unauthorized actions on user data.

## Steps to test

1. Register two accounts (Account A and Account B) on the target application.
2. Authenticate as Account A and capture a request to the /api/customer/{customerId}/generic-popup/.../dismiss-generic-popup endpoint.
3. Replace Account A's customerId in the URL with Account B's customerId while retaining Account A's session/auth token.
4. Send the modified request and observe the response.

## Commands

```text
GET /api/customer/{AccountA_customerId}/generic-popup/.../dismiss-generic-popup HTTP/1.1
Host: example.com
Authorization: Bearer {AccountA_auth_token}
GET /api/customer/{AccountB_customerId}/generic-popup/.../dismiss-generic-popup HTTP/1.1
/api/customer/{customerId}/generic-popup/.../dismiss-generic-popup
```
