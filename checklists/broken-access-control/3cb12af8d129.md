## Use case

The application allows organization roles to bypass project-level access restrictions, enabling unauthorized users to access sensitive project data. This vulnerability matters as it can lead to unauthorized actions within projects, compromising data integrity and security.

## Steps to test

1. Create an organization as the Owner.
2. Add a Manager to the organization.
3. Create a project named 'Free Palestine' and add only the Owner as a member.
4. Log in as the Manager.
5. Attempt to access the 'Free Palestine' project.
6. Observe that the Manager can view project data and perform actions despite not being a member.
