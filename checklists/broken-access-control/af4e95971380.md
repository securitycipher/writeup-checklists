## Use case

Active Directory misconfigurations can lead to unauthorized access and privilege escalation, making it critical for security assessments to identify and exploit these weaknesses. Attackers can leverage misconfigured permissions to gain access to sensitive resources or escalate privileges within the domain.

## Steps to test

1. Use PowerShell to enumerate users in a specific Organizational Unit (OU) to identify potential targets.
2. Check group memberships for privileged groups using Get-ADGroupMember to find users with elevated permissions.
3. Review the Access Control List (ACL) of specific AD objects using Get-Acl to identify misconfigured permissions.
4. Utilize BloodHound to visualize the permission structure and identify potential escalation paths.
5. Look for indirect paths to Domain Admin by analyzing group memberships and ACL entries.

## Commands

```text
Get-ADUser -Filter * -SearchBase 'OU=Finance,DC=corp,DC=example,DC=com'
Get-ADGroupMember -Identity 'Domain Admins'
Get-Acl 'AD:\CN=jdoe,OU=Finance,DC=corp,DC=example,DC=com' | Format-List
SharpHound.exe -CollectionMethod All -OutputDirectory C:\Temp
# Enumerate users in a specific OU
Get-ADUser -Filter * -SearchBase "OU=Finance,DC=corp,DC=example,DC=com"
# See who belongs to a privileged group
Get-ADGroupMember -Identity "Domain Admins"
# Check an object's actual permission list
Get-Acl "AD:\CN=jdoe,OU=Finance,DC=corp,DC=example,DC=com" | Format-List
# Collector run on a domain-joined machine, authorized engagement only
SharpHound.exe -CollectionMethod All -OutputDirectory C:\Temp
```
