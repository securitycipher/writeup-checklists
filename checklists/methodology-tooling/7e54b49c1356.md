## Use case

Clickjacking vulnerabilities allow attackers to trick users into performing unintended actions on trusted websites. This can lead to account takeovers, unauthorized transactions, and data harvesting.

## Steps to test

1. Create a test HTML page with an iframe embedding the target URL using <iframe src='https://example.com/vulnerable-action' style='opacity:0; position:absolute; top:0; left:0; width:100%; height:100%;'></iframe>.
2. Load the test page in a browser.
3. Observe if the target page is successfully embedded without errors.
4. Check for the presence of X-Frame-Options and Content-Security-Policy headers in the response.
5. Attempt to interact with the embedded page to see if actions can be performed without user consent.

# Clickjacking Anatomy
Attack Vector:
1. Attacker creates malicious page
2. Iframe embeds target website
3. Iframe is made invisible/transparent
4. Decoy UI placed on top
5. User clicks decoy → actually clicks target elements
Two Primary Methods:
1. Visual Deception:
- Transparent overlays
- Disguised buttons/links
- Hidden iframes
2. Action Forcing:
- Single click chains multiple actions
- Dragging (likejacking)
- Cursor manipulation
# Basic iframe injection
<iframe src="https://target.com/sensitive-action"
style="opacity:0; position:absolute; top:0; left:0;
width:100%; height:100%;">
</iframe>
# Decoy overlay
<div style="position:absolute; top:100px; left:50px;">
<button>Click to Win $100</button>
</div>

- Access token theft
✓ Medium:
- Profile modifications

- Information disclosure
# Features to Test
Authentication:
- Login/Logout buttons
- Password reset forms
- MFA/2FA configuration
Financial:
- Payment buttons
- Fund transfers
- Subscription changes
Profile:
- Email/phone updates
- Address changes
- Account deletion
Security:
- Security settings
- API key generation
- Email forwarding
Critical:
- Admin actions
- Feature toggles
- Permanent changes
# Look for Missing Protection Headers
Check Response Headers:
- X-Frame-Options (missing = vulnerable)
- Content-Security-Policy (frame-ancestors missing)
Test with:
1. Simple iframe embed
2. Frame-busting bypass attempts
3. Forced action chains

<html>

</iframe>

</html>
# Step 2: Observe
- Can you embed the page?
- Is it loaded successfully?
- Are there any error messages?
# Step 3: Test Various Target Actions
- Login forms
