## Use case

The SSL Search tool allows for the identification of infrastructure by scanning SSL certificates across various IP addresses. This is crucial for understanding the public attack surface of a target and identifying potential vulnerabilities.

## Steps to test

1. Install the SSL Search tool using the command 'go install github.com/HarshVaragiya/sslsearch@latest'.
2. Run a targeted scan on AWS by executing 'sslsearch aws --keyword-regex '.*target.*' --jarm --server-header' to identify relevant infrastructure.
3. Perform a scan on GCP for a specific region with 'sslsearch gcp --keyword-regex '.*' --region-regex 'us-west4' --jarm --server-header'.
4. Scan a specific CIDR range using 'sslsearch cidr 10.10.10.0/24 --keyword-regex '.*target.*' --console-out' to find potential targets.
5. Optionally, conduct a broader scan of the entire Internet with 'sslsearch cidr 0.0.0.0/0 --keyword-regex '.*' --threads 20000 --jarm --server-header --jarm-threads 400 --server-header-threads 200'.

## Commands

```text
go install github.com/HarshVaragiya/sslsearch@latest
sslsearch aws --keyword-regex '.*target.*' --jarm --server-header
sslsearch gcp --keyword-regex '.*' --region-regex 'us-west4' --jarm --server-header
sslsearch cidr 10.10.10.0/24 --keyword-regex '.*target.*' --console-out
sslsearch cidr 0.0.0.0/0 --keyword-regex '.*' --threads 20000 --jarm --server-header --jarm-threads 400 --server-header-threads 200
sslsearch cidr 10.10.10.0/24 --keyword-regex '.*taget.*' --console-out
```
