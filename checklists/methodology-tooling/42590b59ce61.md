## Use case

BountyForge orchestrates multiple specialized security agents to identify vulnerabilities across various attack surfaces, significantly improving the efficiency of bug bounty hunting. This approach allows for simultaneous testing of web APIs, smart contracts, and business logic vulnerabilities.

## Steps to test

1. Identify the target application and define the scope.
2. Run the reconnaissance agent to discover attack surfaces using tools like nmap and amass.
3. Launch the Web/API security agent to test for vulnerabilities such as SQL injection and XSS.
4. Utilize the Access Control agent to check for role bypass and initialization hijacking.
5. Execute the Business Logic agent to analyze workflows for potential bypasses.
6. Validate findings through the four validation gates to confirm their impact and exploitability.
