## Use case

Burp Suite's Repeater, Decoder, and Comparer tools allow testers to manipulate and analyze HTTP requests and responses efficiently. This is crucial for identifying vulnerabilities such as improper input handling or authentication weaknesses.

## Steps to test

1. Launch Burp Suite and start a temporary project with defaults.
2. Enable intercept in the Proxy tab and route your browser through Burp.
3. Visit http://example.com and intercept the request.
4. Right-click the intercepted request and select 'Send to Repeater'.
5. In the Repeater tab, modify the request path from GET / to GET /nonexistent and click 'Send'.
6. Observe the response status code and note any differences.
