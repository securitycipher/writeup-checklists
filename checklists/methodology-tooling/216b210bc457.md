## Use case

The article outlines essential operational security (OPSEC) practices for a fresh Kali Linux installation, emphasizing the importance of full-disk encryption, VPN usage with a kill switch, and firewall configuration to mitigate risks associated with a compromised environment.

## Steps to test

1. Install Kali Linux and select 'Guided — use entire disk and set up encrypted LVM' during partitioning.
2. Set a strong passphrase for full-disk encryption (FDE).
3. Install a VPN client and ensure the kill switch is enabled.
4. Configure the firewall with 'sudo ufw default deny incoming' and 'sudo ufw enable'.
5. Set up MAC randomization by creating '/etc/NetworkManager/conf.d/00-macrandomize.conf' with the specified configurations.
6. Use 'unset HISTFILE' in your shell to prevent history from persisting sensitive commands.
