## Use case

The mobile app was vulnerable due to its reliance on undocumented API endpoints and improper handling of certificate authorities, which allowed for traffic interception and manipulation. This was critical as it revealed sensitive information and allowed for unauthorized actions within the app.

## Steps to test

1. Install mitmproxy on your machine.
2. Set your mobile device's proxy to your machine's IP address on port 8080.
3. Visit mitm.it on your mobile browser and install the CA certificate.
4. Use adb to set up a reverse proxy: 'adb reverse tcp:8080 tcp:8080'.
5. Modify the app's network_security_config.xml to trust user-installed CAs.
6. Rebuild the APK with the patched XML and ensure no resource IDs are renumbered.
7. Launch the app and observe the traffic through mitmproxy.

## Commands

```text
adb reverse tcp:8080 tcp:8080
mitmproxy --ignore-hosts 'play.googleapis.com'
```
