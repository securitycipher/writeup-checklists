## Use case

Malicious PDFs can exploit vulnerabilities in PDF viewers, making it crucial to analyze and sanitize documents before distribution. This process helps prevent potential attacks that could compromise sensitive information or systems.

## Steps to test

1. Receive the suspicious PDF document for analysis.
2. Calculate the SHA-256 hash of the PDF using 'sha256sum suspicious.pdf'.
3. Inspect the PDF metadata with 'pdfinfo suspicious.pdf'.
4. Extract and inspect PDF objects using 'strings suspicious.pdf | grep -Ei '/JavaScript|/JS|/OpenAction|/Launch|/EmbeddedFile'.
5. Identify any suspicious features and assign risk indicators based on findings.
6. Sanitize the PDF if required and re-scan the sanitized document.
