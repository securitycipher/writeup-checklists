## Use case

HTTPie forwards untrusted HTTP response data directly to the terminal without sanitizing ANSI escape sequences, allowing an attacker to manipulate terminal output and potentially execute commands or phishing attacks.

## Steps to test

1. Set up a malicious HTTP server that returns a crafted HTTP response containing ANSI escape sequences.
2. Use HTTPie to make a request to the malicious server.
3. Observe the terminal output for any unexpected behavior, such as altered text or hyperlinks.
4. Test various escape sequences to see their effects on the terminal display.
