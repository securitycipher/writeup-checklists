## Use case

The web application was vulnerable to SQL injection through user input parameters, allowing an attacker to manipulate database queries and potentially gain unauthorized access to sensitive data.

## Steps to test

1. Use Google Dork to find vulnerable PHP scripts by searching for 'inurl:<SearchVulnerablePHPScript> site:<targetdomain.com>'.
2. Save the search results in a .html file and use grep to extract URLs, removing duplicates with sort.
3. Select a URL from the results and append a SQL injection payload to the vulnerable parameter in the browser.
4. Use sqlmap to test the parameter for SQL injection by running 'sqlmap -u <URL> --level=5 --risk=3 --dbs'.

## Commands

```text
sqlmap -u '<URL>' --level=5 --risk=3 --dbs
```
