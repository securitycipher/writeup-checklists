## Use case

SQL Injection vulnerabilities allow attackers to manipulate database queries by injecting malicious SQL code. This can lead to unauthorized data access, data manipulation, or even full database compromise.

## Steps to test

1. Identify input fields in the web application that interact with a database, such as login forms or search boxes.
2. Input a single quote (') into the field to test for SQL injection vulnerabilities.
3. Observe the application's response for SQL error messages or unexpected behavior.
4. Use Sqlmap to automate the detection and exploitation of SQL injection by running 'sqlmap -u http://example.com/vulnerable_endpoint?param=value --dbs'.

## Commands

```text
sqlmap -u http://example.com/vulnerable_endpoint?param=value --dbs
sqlmap -u http://example.com/vulnerable_endpoint?param=value --dump
```
