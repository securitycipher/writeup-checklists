## Use case

The login form was vulnerable to SQL injection, allowing an attacker to bypass authentication by manipulating the username input. This vulnerability matters because it can lead to unauthorized access to user accounts without needing the correct password.

## Steps to test

1. Navigate to the login page of the application.
2. In the username field, input 'administrator'-- (including the single quote and double hyphen).
3. In the password field, enter any arbitrary password.
4. Submit the login form and observe if access is granted without the correct password.
