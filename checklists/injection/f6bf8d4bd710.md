## Use case

The application is vulnerable to SQL injection through the User-Agent HTTP header, allowing an attacker to manipulate SQL queries and potentially gain unauthorized access to the database. This vulnerability matters because it can lead to data leakage or corruption.

## Steps to test

1. Use a tool like Burp Suite or curl to send a request to the target application with a custom User-Agent header.
2. Set the User-Agent header to a value that includes a single quote, such as ' or any other SQL injection payload.
3. Observe the application's response for SQL errors or unexpected behavior.
4. If the application logs the User-Agent, check the logs to see if the injected payload was executed.
5. Attempt to extract data from the database using UNION-based SQL injection techniques.
