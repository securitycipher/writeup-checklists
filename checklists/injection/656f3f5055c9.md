## Use case

The DVWA application allows for SQL injection vulnerabilities at both low and medium security levels, which can lead to unauthorized access to sensitive data. This is critical for penetration testing as it demonstrates the importance of input validation and database security.

## Steps to test

1. Open DVWA in your browser at http://192.168.88.130/dvwa/
2. Navigate to the SQL Injection section.
3. Enter a SQL injection payload in the input field (e.g., ' OR '1'='1).
4. Submit the form and observe the response for any database errors or unexpected data.
5. Use Burp Suite to intercept and modify requests to test different payloads.
6. Confirm successful injection by checking for unauthorized data retrieval.
