## Use case

The vulnerability exists in the jsonArrayContains filter function of GeoServer, allowing unauthenticated SQL injection through crafted WFS or WMS requests. This can lead to remote code execution against the database backend, posing a significant risk to public-facing geospatial data services.

## Steps to test

1. Identify a public GeoServer instance that accepts WFS or WMS requests.
2. Craft a request with the jsonArrayContains filter, e.g., jsonArrayContains(<column>, <pointer>, '<injection_value>'); where <injection_value> contains a single quote followed by SQL payload.
3. Send the crafted request to the GeoServer endpoint and observe the response for SQL errors or unexpected behavior.
4. If possible, monitor the database logs for executed SQL queries to confirm successful injection.
