## Use case

The e-commerce website's diagnostic feature accepted user input for a hostname or IP address, which could be exploited for OS Command Injection due to improper validation, allowing attackers to execute arbitrary commands on the server.

## Steps to test

1. Access the endpoint POST /diagnostics/ping with the parameter host.
2. Input a normal value like example.com and observe the response.
3. Input a harmless but suspicious value such as example.com; ls to test for command injection.
4. Analyze the response for unusual behavior or error messages indicating command execution.
5. Confirm the vulnerability by attempting to create a marker file using a benign command.
6. Validate that the marker file is created in the expected directory.
