## Use case

The SQL injection vulnerability allowed an unauthenticated user to bypass the login page and access the IncidentDesk dashboard, enabling unauthorized access to sensitive functionalities intended for authenticated users.

## Steps to test

1. Navigate to the login page of the application.
2. In the User Identifier field, enter the payload: admin' or '1'='1'#.
3. Click the submit button.
4. Wait for the response to confirm successful login.
