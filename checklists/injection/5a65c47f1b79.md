## Use case

The article discusses various types of injection vulnerabilities, particularly SQL Injection, which allows attackers to manipulate database queries through unvalidated user input. This can lead to severe consequences such as authentication bypass and data exposure.

## Steps to test

1. Identify an input field that interacts with a database, such as a login form.
2. Enter a payload like '' OR '1'='1' in the username field to test for SQL Injection.
3. Observe if the application grants access without valid credentials.
4. For XSS, input <script>alert('XSS')</script> in a search field and check if the script executes.
5. For Command Injection, input a command like ; cat /etc/passwd in a vulnerable command execution feature.
6. For LDAP Injection, input *)(uid=*))(|(uid=* in the username field and check for authentication bypass.

;    → command separator
&&   → run next command if first succeeds
