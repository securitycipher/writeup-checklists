## Use case

The article describes a blind LDAP injection vulnerability in a password reset form that allows an attacker to extract sensitive employee directory data without needing valid credentials. This is critical as it exposes organizational structure and user information, which can be leveraged for further attacks.

## Steps to test

1. Identify a password reset form that interacts with an LDAP directory.
2. Submit an email address with the payload 'test@test.com)(objectClass=*' to trigger a true response.
3. Submit an email address with the payload 'test@test.com)(!(objectClass=*)' to trigger a false response.
4. Analyze the responses to confirm the presence of a boolean oracle based on the returned messages.
