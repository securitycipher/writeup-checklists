## Use case

The application was vulnerable to NoSQL injection, allowing an attacker to manipulate queries and bypass authentication or extract sensitive data. This vulnerability matters as it can lead to unauthorized access and data leakage.

## Steps to test

1. Identify an input field that accepts user input for NoSQL queries, such as a login form or product filter.
2. Inject a payload that manipulates the query logic, such as using the $ne operator in the password field to bypass authentication.
3. Use the $regex operator to find valid usernames if the exact username is unknown.
4. For data extraction, append a single quote to the user parameter to test for injection, then use JavaScript expressions to retrieve sensitive information.
