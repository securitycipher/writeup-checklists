## Use case

SQL injection vulnerabilities can allow attackers to manipulate database queries, potentially leading to unauthorized data access or even full server compromise. This article outlines a systematic approach to identifying and exploiting SQLi in bug bounty programs.

## Steps to test

1. Map all parameters of the target application using tools like subfinder, amass, and httpx.
2. Confirm potential SQL injection points by sending a single quote (') to see if it breaks the response.
3. Test for boolean-based SQL injection by sending payloads like 'id=1 AND 1=1' and 'id=1 AND 1=2' to compare responses.
4. If a parameter is confirmed as vulnerable, escalate to union-based extraction or blind SQL injection techniques.
5. Use sqlmap to automate exploitation once a parameter is confirmed vulnerable.

## Commands

```text
subfinder -d example.com
httpx -l urls.txt
curl -X GET 'https://example.com/api/reports?sort='
sqlmap -u 'https://example.com/api/reports?sort=' --dbs
curl -X GET 'https://example.com/api/reports?sort=1' -H 'User-Agent: test'
```
