## Use case

The DVWA application is vulnerable to Blind SQL Injection, allowing an attacker to infer information about the database based on the application's responses to crafted SQL queries. This vulnerability is critical as it can lead to unauthorized data access and manipulation.

## Steps to test

1. Start with a valid user ID, such as 1, and observe the response indicating the user ID exists.
2. Test with a non-existent user ID, such as 9999, to confirm the application returns a response indicating the user ID is missing.
3. Use Burp Suite to intercept the POST request when submitting a user ID.
4. Modify the id parameter in the request body to include a Boolean True payload, such as 'id=1 AND 1=1#', and forward the request.
5. Observe the response to confirm whether the user ID exists based on the application's behavior.
6. Repeat the process with a Boolean False payload, such as 'id=1 AND 1=0#', and a time-based payload, such as 'id=1 AND SLEEP(5)#', to test for time delays.
