## Use case

The 'Export to Excel' feature allowed users to filter transactions, which was vulnerable to SQL Injection. This vulnerability led to a full database takeover, highlighting the risks of unmonitored internal services.

## Steps to test

1. Navigate to the 'Account Analytics' tab in the application.
2. Click on the 'Download Custom Transaction Audit (.xlsx)' button.
3. Intercept the POST request using Burp Suite.
4. Modify the parameters in the request to include SQL injection payloads.
5. Send the modified request and observe the response for database information.

## Commands

```text
POST /api/export-audit HTTP/1.1
Host: example.com
Content-Type: application/json
Body: {"date_range": "2021-01-01 to 2021-12-31", "transaction_type": "1 OR 1=1", "category": "all"}
```
