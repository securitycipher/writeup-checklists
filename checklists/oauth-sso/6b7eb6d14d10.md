## Use case

The OAuth callback and redirect mechanism was vulnerable due to improper validation of host parameters, allowing attackers to manipulate the callback URL and capture user credentials.

## Steps to test

1. Identify an OAuth endpoint that uses host parameter validation.
2. Append ';@attacker.com' to the host parameter in the OAuth request.
3. Observe if the server validates the host parameter correctly.
4. Check if the client sends credentials to the attacker's domain instead of the legitimate one.

## Commands

```text
GET https://example.com/oauth/authorize?client_id=CLIENT_ID&redirect_uri=https://periscope.tv;@attacker.com&response_type=code
```
