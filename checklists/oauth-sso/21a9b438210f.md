## Use case

The article describes a vulnerability in an unauthenticated OAuth registration endpoint that allows an attacker to register a malicious client and perform a full account takeover by tricking victims into logging in through the attacker's client. This misconfiguration can lead to unauthorized access to user accounts without any special privileges required from the attacker.

## Steps to test

1. Perform a GET request to /.well-known/openid-configuration to identify the registration endpoint.
2. Send a POST request to /oauth/register with a JSON payload to register a new client without authentication.
3. Capture the client_id from the response.
4. Generate a PKCE pair (code_verifier and code_challenge).
5. Construct the authorization URL using the registered client_id and send it to the victim.
6. After the victim logs in, capture the authorization code from the redirect to the attacker's callback URL.
7. Send a POST request to /oauth/token with the captured authorization code and the code_verifier to obtain the access token.
