## Use case

The vulnerability allowed an attacker to take over an account by exploiting OAuth misconfigurations, specifically by linking accounts with the same email address across different authentication methods.

## Steps to test

1. Sign up for an account using the victim's email and a password on the target application.
2. Log out of the application.
3. Attempt to sign up again using the same email address but choose the Google sign-up option.
4. If the application allows you to log in without email verification, you have successfully exploited the pre-account takeover vulnerability.

## Commands

```text
POST https://example.com/signup
Content-Type: application/json
Body: {"email": "victim@example.com", "password": "yourpassword"}
POST https://example.com/signup/google
Body: {"email": "victim@example.com"}
```
