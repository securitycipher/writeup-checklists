## Use case

The application allowed unauthenticated access to its frontend and trusted social login providers without proper domain validation, leading to an authentication bypass. This misconfiguration exposed sensitive operational data to unauthorized users.

## Steps to test

1. Run subfinder to enumerate subdomains for the target application.
2. Use httpx to check the HTTP status codes and identify the target subdomain.
3. Send a GET request to https://target.com/.auth/me and check for a 200 OK response with a null clientPrincipal.
4. Trace the OAuth login redirects for each identity provider (e.g., Azure, Google, GitHub) to identify misconfigurations.
5. Complete the OAuth flow using a free account (e.g., Gmail) and verify if you can access the application as an authenticated user.
