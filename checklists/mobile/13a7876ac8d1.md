## Use case

Flutter applications may not honor the Android system proxy configuration, leading to difficulties in intercepting traffic with Burp Suite. This misconfiguration can prevent security testers from effectively analyzing API requests made by the application.

## Steps to test

1. Open Terminal and list available Android Virtual Devices using: ~/Library/Android/sdk/emulator/emulator -list-avds
2. Close any running Android Studio Emulator completely.
3. Launch the emulator with the proxy configuration using: ~/Library/Android/sdk/emulator/emulator -avd Non_Rooted -http-proxy http://192.168.1.138:8082
4. Verify ADB connectivity by running: adb devices
5. Test HTTP traffic by opening Chrome in the emulator and visiting: http://example.com, then check Burp Suite for the request.
6. Test HTTPS traffic by visiting: https://example.com in Chrome and ensure requests appear in Burp Suite.
