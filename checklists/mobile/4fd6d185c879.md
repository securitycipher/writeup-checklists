## Use case

Android applications can have vulnerabilities due to improper configurations in the AndroidManifest.xml file, such as allowing cleartext traffic or setting debuggable to true. These misconfigurations can lead to unauthorized access, data leakage, and exploitation of sensitive information.

## Steps to test

1. Extract the APK from the target Android device using adb shell pm list packages and adb pull <APK_PATH>.
2. Open the APK with JADX-GUI to analyze the AndroidManifest.xml file.
3. Check for the 'android:allowBackup' attribute and ensure it is set to false.
4. Verify that 'android:debuggable' is set to false to prevent debugging in production.
5. Look for 'android:usesCleartextTraffic' and ensure it is set to false to prevent unencrypted traffic.
6. Inspect for any components with 'android:exported' set to true and assess their security implications.

## Commands

```text
adb shell pm list packages
adb pull /data/app/<package_name>/base.apk
jadx-gui <path_to_apk>
grep 'allowBackup' AndroidManifest.xml
grep 'debuggable' AndroidManifest.xml
grep 'usesCleartextTraffic' AndroidManifest.xml
```
