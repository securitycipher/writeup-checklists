## Use case

Mobile applications often expose sensitive data through insecure JavaScript bridges. This can lead to unauthorized access to application data or functionality, making it crucial to test for these vulnerabilities.

## Steps to test

1. Identify the mobile application and install it on a test device.
2. Use a tool like Frida or Objection to hook into the JavaScript bridge of the application.
3. Inspect the exposed methods and properties available through the bridge.
4. Attempt to invoke sensitive methods or access sensitive data without proper authentication or authorization.
5. Monitor the application's response to determine if unauthorized actions were successful.

## Commands

```text
frida -U -f com.example.app -l script.js --no-pause
objection --gadget com.example.app explore
```
