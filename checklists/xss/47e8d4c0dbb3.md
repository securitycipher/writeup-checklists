## Use case

The resume upload feature on the HR portal allowed for a stored XSS vulnerability due to improper handling of file names, enabling an attacker to execute JavaScript in the HR admin context, leading to session cookie theft.

## Steps to test

1. Navigate to the job application page at https://career.pumb.ua/vacancy/junior.
2. Locate the resume upload field and create a file with the name '><img src=x onerror=alert(1337)>.jpg'.
3. Fill in the form with test data and upload the crafted file.
4. Submit the application and observe the alert firing to confirm stored XSS.
5. Reload the page or open a new incognito session to verify the payload persists.
6. Test cookie theft by using the payload '><img src=x onerror=alert(document.cookie)>.jpg' to confirm session cookie exposure.
