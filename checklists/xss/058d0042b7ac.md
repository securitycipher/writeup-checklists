## Use case

The application allowed an attacker-controlled URL to be set as the src of an iframe without proper validation, leading to arbitrary JavaScript execution in the target's origin. This vulnerability matters because it can be exploited to execute malicious scripts in the context of the victim's session.

## Steps to test

1. Open the vulnerable endpoint: /girls?isWhatsApp=1&whatsAppReturn=<encoded-JavaScript-URI>
2. Open DevTools (F12) and navigate to the Console.
3. Inspect the hydrated page for the iframe generated by the application.
4. Wait for the hydration process to complete.
5. Verify execution by checking for a harmless marker in the top-level window.
