## Use case

The article outlines a systematic approach to finding Cross-Site Scripting (XSS) vulnerabilities in web applications, emphasizing the importance of understanding different types of XSS and the need for thorough reconnaissance before testing.

## Steps to test

1. Identify user-controlled input points such as URL parameters, form fields, and HTTP headers.
2. Send a unique marker string to each input point and observe where it reappears in the response.
3. Analyze the context of the reflection points to determine how to craft context-aware payloads.
4. Test for DOM-based XSS by identifying sources and sinks in JavaScript files.
5. Use tools like Burp Suite and Dalfox for automated testing and parameter discovery.
