## Use case

DOM XSS vulnerabilities occur when attacker-controlled data flows from a source to a sink without proper sanitization, allowing for malicious scripts to execute in the user's browser. This is particularly relevant in modern single-page applications (SPAs) where traditional WAFs may not detect such attacks.

## Steps to test

1. Identify a web application that uses JavaScript frameworks like React, Vue, or Angular.
2. Inspect the application for potential sources of attacker-controlled data such as location.hash or document.referrer.
3. Determine if any of these sources flow directly into dangerous sinks like element.innerHTML or eval() without sanitization.
4. Craft a payload that exploits this flow and test it in the browser to see if it executes.
