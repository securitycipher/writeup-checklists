## Use case

The e-commerce application allowed for user input to be reflected in various JavaScript contexts, potentially leading to DOM-based XSS vulnerabilities. Understanding how to identify and triage these sinks is crucial for effective testing.

## Steps to test

1. Navigate to the target e-commerce application.
2. Use the search bar to input a unique string, such as 'M4rduk!J4m3s!W4s!H3r3!'.
3. Analyze the page source for reflections of the input string.
4. Use Burp Suite's DOM Invader to check for sinks by searching for the input string in the built-in browser.
5. Review the results and categorize the sinks based on their context and potential exploitability.
6. Use the Exploit button on promising sinks to validate their behavior.
