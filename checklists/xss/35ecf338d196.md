## Use case

The application allowed users to upload SVG files as custom logos, which were not properly sanitized, leading to a Stored Cross-Site Scripting vulnerability that could execute arbitrary JavaScript in the context of other users.

## Steps to test

1. Navigate to the organization settings page of the application.
2. Locate the file upload field for the custom logo.
3. Prepare an SVG file containing malicious JavaScript code.
4. Upload the SVG file using the POST request to /api/v1/workspace/logo.
5. Access the workspace where the logo is displayed to trigger the XSS payload.
6. Observe the execution of the JavaScript code in the browser.
