## Use case

The application reflected user input directly into an HTML attribute without proper encoding, allowing for reflected XSS via attribute injection. This vulnerability can lead to arbitrary JavaScript execution in the context of the victim's session.

## Steps to test

1. Identify a vulnerable input field that reflects user input into an HTML attribute.
2. Craft a payload that closes the original attribute and injects a new event handler, such as: R3za" onfocus=alert(origin) autofocus tabindex=1.
3. Submit the payload using a POST request to the vulnerable endpoint.
4. Observe the execution of the JavaScript when the page loads.
