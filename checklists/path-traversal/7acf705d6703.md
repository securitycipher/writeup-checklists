## Use case

The application allows users to request image files by filename, but does not properly validate the input, enabling attackers to access sensitive files on the server. This can lead to exposure of critical information such as user credentials and configuration files.

## Steps to test

1. Identify any parameters that reference a filename or file path, such as 'filename' or 'file'.
2. Send a request with a basic traversal payload, e.g., '../../../etc/passwd'.
3. Check the response for the contents of '/etc/passwd' to confirm path traversal.
4. If the initial payload fails, attempt the following bypass techniques in order: absolute path, nested traversal sequences, URL encoding, base folder bypass, and null byte injection.
