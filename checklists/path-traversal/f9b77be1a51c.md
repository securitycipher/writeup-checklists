## Use case

The application allows users to specify a filename parameter to retrieve product images, but it does not properly validate this input, leading to a Path Traversal vulnerability that can be exploited to access sensitive files like /etc/passwd.

## Steps to test

1. Access the PortSwigger File Path Traversal lab.
2. Right-click on a product image and select 'Open Image in New Tab' to view the URL.
3. Identify the filename parameter in the URL that corresponds to the image.
4. Modify the filename parameter to include directory traversal sequences (e.g., ../../../../etc/passwd).
5. Load the modified request and observe the response for any errors indicating the application processed the request.
6. Confirm the Path Traversal vulnerability if the application attempts to access the unauthorized file.

## Commands

```text
GET /images/product_image.jpg?filename=../../../../etc/passwd HTTP/1.1
Host: example.com
```
