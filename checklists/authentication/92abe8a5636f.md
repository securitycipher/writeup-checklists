## Use case

The application improperly validates JWT tokens, allowing an authenticated low-privileged user to impersonate an administrator by modifying the JWT payload and using the 'none' algorithm, which can lead to unauthorized access and privilege escalation.

## Steps to test

1. Intercept the login request using Burp Suite.
2. Capture the JWT token from the response after authentication.
3. Modify the JWT header to change the algorithm to 'none'.
4. Change the email field in the payload to the email address of an administrator account.
5. Replace the original token with the modified JWT and send the request back to the server.
6. Verify if the application accepts the modified token and grants administrator access.

## Commands

```text
POST /login HTTP/1.1
Host: example.com
Content-Type: application/json
Authorization: Bearer <original_jwt_token>
{"email":"admin@example.com"}
```
