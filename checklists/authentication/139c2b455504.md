## Use case

The article discusses a password reset vulnerability that allows attackers to exploit the lack of rate limiting and improper token handling, potentially leading to full account takeover. This is critical as it can compromise user accounts and sensitive data.

## Steps to test

1. Verify the target application is within the authorized bug bounty scope.
2. Log in to the target application and confirm the registered email address is verified.
3. Trigger a password reset by clicking on 'Forgot Password' and entering the registered email address.
4. Intercept the password reset request using Burp Suite.
5. Send the intercepted request to Burp Intruder and configure it to send multiple requests.
6. Analyze the HTTP responses for repeated 200 OK status and monitor the email inbox for excessive reset emails.
