## Use case

The vulnerability allowed unauthenticated external users to access a development environment that was intended to require corporate SSO authentication due to a misconfiguration where the origin server did not enforce the same authentication checks as the CDN.

## Steps to test

1. Identify the CDN-protected site and confirm that it requires SSO by making a request to the CDN URL.
2. Use DNS enumeration to find the origin server's hostname that bypasses the CDN.
3. Make a direct request to the origin server using the Host header set to the protected site.
4. Verify the response to check if it returns HTTP 200 OK without requiring SSO.
