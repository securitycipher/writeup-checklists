## Use case

The application has a logic flaw in its brute-force protection mechanism, allowing an attacker to bypass the lockout after a series of incorrect password attempts by inserting a valid login attempt in between. This vulnerability matters as it can lead to unauthorized access to user accounts.

## Steps to test

1. Log in with valid credentials for user 'Carlos'.
2. Intercept the login request in Burp Suite and send it to Repeater.
3. Attempt to log in with incorrect passwords while monitoring the response.
4. After three incorrect attempts, note the one-minute block period.
5. Create a macro in Burp Suite that sends a valid login request (status code 302) after a set number of incorrect attempts.
6. Set up an Intruder attack with 'carlos' as the username and a list of passwords as payloads, ensuring the attack type is 'Sniper'.
7. Start the attack and observe the responses for successful login attempts.

## Commands

```text
ctrl + R (to send the request to Repeater)
ctrl + I (to send the request to Intruder)
Set payload position on the password field in Intruder.
Create a new resource pool with maximum concurrent requests set to 1.
```
