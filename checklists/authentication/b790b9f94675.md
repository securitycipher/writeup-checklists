## Use case

The article describes a vulnerability in a university's e-document system that allowed an attacker to exploit a password-reset bug to gain access to sensitive databases. This was critical as it exposed personal and financial information of over a million students.

## Steps to test

1. Identify the target's password reset endpoint.
2. Craft a POST request to the password reset endpoint with a valid user identifier.
3. Observe the response for any indication of a successful password reset or access.
4. Use the derived password to authenticate against the database server.
