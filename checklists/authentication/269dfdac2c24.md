## Use case

The vulnerability lies in the implementation of two-factor authentication (2FA) where an access token is issued before the second factor is checked, allowing attackers to gain full account access with just the password. This undermines the purpose of 2FA, as it does not provide any additional security in this context.

## Steps to test

1. Enable 2FA on a test account.
2. Log out and start a fresh session.
3. Log in with the correct email and password.
4. Capture the response headers for the `Set-Cookie` and the access token.
5. Use the captured access token directly against the API without providing a 2FA code.

## Commands

```text
POST /login HTTP/1.1
Host: example.com
Content-Type: application/json
Authorization: Basic base64(email:password)
{}
```
