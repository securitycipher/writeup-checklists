## Use case

The vulnerability was in the Emergency Password Recovery feature, which allowed an attacker to impersonate any executive by exploiting the password reset mechanism. This was critical as it enabled unauthorized access to sensitive accounts within a multi-tenant architecture.

## Steps to test

1. Identify the target platform that uses SSO for authentication.
2. Attempt to recover an account using the Emergency Password Recovery feature by entering a corporate email associated with an executive.
3. Observe the response from the server to determine if it indicates a valid recovery process.
4. If successful, follow the recovery link or process to reset the password and gain access to the executive's account.

## Commands

```text
POST https://example.com/password-recovery
Body: { 'email': 'executive@example.com' }
```
