## Use case

The vulnerability allowed an attacker to bypass Two-Factor Authentication (2FA) by directly accessing a protected endpoint after logging in with valid credentials. This flaw undermined the security provided by 2FA, making it ineffective.

## Steps to test

1. Log in to the web application using valid username and password.
2. Observe the 2FA prompt and retrieve the 2FA code from the email client.
3. Log out and attempt to log in using the victim's username and password.
4. When prompted for the 2FA code, instead of entering a code, modify the URL to '/my-account'.
5. Access the modified URL to confirm successful login without 2FA.

## Commands

```text
GET https://example.com/login
POST https://example.com/login -d 'username=victim_username&password=victim_password'
GET https://example.com/my-account
```
