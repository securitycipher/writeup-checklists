## Use case

The password reset functionality allowed an attacker to reset another user's password by manipulating the username parameter in the request, which could lead to unauthorized access to the victim's account.

## Steps to test

1. Log in with valid credentials to access the account.
2. Log out and navigate to the password reset page.
3. Intercept the password reset request using Burp Suite.
4. Change the username parameter in the request to the target user's username (e.g., 'carlos').
5. Submit the request and follow the redirection.
6. Attempt to log in with the target username and the new password.

## Commands

```text
POST /password-reset HTTP/1.1
Host: example.com
Content-Type: application/x-www-form-urlencoded
username=carlos&new_password=YourNewPassword
```
