## Use case

The password reset process was vulnerable due to improper validation of the username parameter against the reset token, allowing an attacker to reset another user's password without their knowledge.

## Steps to test

1. Navigate to the login page of the application.
2. Click on the 'Forgot password?' link.
3. Enter a valid username (e.g., 'wiener') to initiate the password reset process.
4. Intercept the POST request for the password change using Burp Suite.
5. Change the 'username' parameter in the request body to the target user's username (e.g., 'carlos').
6. Forward the modified request to complete the password reset.
7. Log in using the new password for the target user's account.
