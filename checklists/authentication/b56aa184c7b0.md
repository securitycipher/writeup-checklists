## Use case

MFA systems are often vulnerable due to user impatience and misconfigurations, allowing attackers to bypass security measures through techniques like MFA fatigue attacks. This matters because it highlights the weaknesses in user behavior and system design that can lead to unauthorized access.

## Steps to test

1. Identify a target with MFA enabled.
2. Send multiple push notifications to the target's device to create fatigue.
3. Monitor for the target's response to the notifications.
4. Attempt to authenticate using the MFA code received after the target is overwhelmed.
