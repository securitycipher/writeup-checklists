## Use case

The article discusses various methods to exploit broken authentication mechanisms, allowing attackers to impersonate users, including admins, which can lead to unauthorized access to sensitive information and functionalities.

## Steps to test

1. Capture the login request in Burp Suite and send it to Intruder.
2. Load a wordlist of leaked username/password pairs and fire it at the endpoint.
3. Check for CAPTCHA, rate limits, and lockout mechanisms after failed login attempts.
4. For username enumeration, submit known real and fake emails on the login or 'forgot password' page and compare error messages.
5. To test for session fixation, request a session ID before logging in and send it to a victim through a crafted link.
6. Capture session cookies before logging out and replay them to check if the session is still valid.

## Commands

```text
curl -X POST -d 'username=known_user&password=leaked_password' https://example.com/login
curl -X POST -d 'email=real@example.com' https://example.com/forgot-password
curl -X GET -b 'session_id=old_session_cookie' https://example.com/protected-resource
curl -X GET 'https://example.com/login?redirect_uri=https://attacker.com'
curl -X POST -d 'session_id=fixed_session_id' https://example.com/login
```
