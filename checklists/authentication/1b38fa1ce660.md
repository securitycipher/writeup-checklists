## Use case

The vulnerability was in Instagram's password reset endpoint, where the rate limiting mechanism failed, allowing an attacker to send a large number of reset codes in a short time, potentially compromising user accounts.

## Steps to test

1. Identify the password reset endpoint for Instagram.
2. Monitor the response time and behavior of the endpoint when sending multiple reset requests.
3. Send a reset request for a target account and note the response.
4. Rapidly send multiple reset requests for the same account using a script to bypass rate limiting.
5. Check if the account can be reset successfully after a certain number of requests.

## Commands

```text
POST https://www.instagram.com/accounts/password/reset/ HTTP/1.1
Content-Type: application/json
Body: {"username": "target_username"}
```
