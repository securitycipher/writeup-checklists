## Use case

The vulnerable code allows an attacker to set a specific session ID for a user's session, enabling session fixation attacks. This is critical as it can lead to unauthorized access and impersonation of users.

## Steps to test

1. Identify a login page that uses session management.
2. Intercept the request to the login endpoint using a proxy tool.
3. Modify the request to include a parameter 'sessionId' with a value of your choice (e.g., 'maliciousSessionId').
4. Send the modified request to log in as a user.
5. After logging in, use the same 'sessionId' to access protected resources.
6. Verify if you can access the user's session and perform actions as them.

## Commands

```text
POST /login HTTP/1.1
Host: example.com
Content-Type: application/x-www-form-urlencoded
sessionId=maliciousSessionId&username=user&password=pass
HttpSession session = request.getSession();
String sessionId = request.getParameter("sessionId");
if (sessionId != null) {
session.setId(sessionId);
}
```
