## Use case

Email security testing can reveal vulnerabilities in authentication mechanisms, such as weak password reset flows that could allow attackers to gain unauthorized access to accounts. This is critical as compromised accounts can lead to data breaches and loss of sensitive information.

## Steps to test

1. Define the scope of testing, including authorized domains and mail servers.
2. Perform DNS reconnaissance to identify MX records using 'dig MX example.com' or 'nslookup -type=MX example.com'.
3. Inspect the SPF record with 'dig TXT example.com' to verify authorized sending servers.
4. Check DKIM configuration by querying the relevant DKIM record using the selector.
5. Test the password reset functionality by requesting a reset token and analyzing its predictability and expiration.
