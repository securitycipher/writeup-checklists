## Use case

The subdomain had a hidden admin portal that required authentication. The vulnerability arose from the potential use of default credentials, allowing unauthorized access to sensitive admin functionalities.

## Steps to test

1. Perform passive subdomain enumeration using a tool like 'subfinder' or 'amass'.
2. Identify active subdomains using 'httpx' with the command: 'httpx -l subdomains.txt -o active_subdomains.txt'.
3. Access the identified subdomain (e.g., 'staging.redacted.com') in a web browser.
4. Observe the authentication prompt for username and password.
5. Attempt to log in using common default credentials (e.g., 'admin:admin', 'admin:password').
6. If successful, document the access gained and any sensitive functionalities available.

## Commands

```text
subfinder -d example.com -o subdomains.txt
httpx -l subdomains.txt -o active_subdomains.txt
curl -u admin:admin http://staging.redacted.com
```
