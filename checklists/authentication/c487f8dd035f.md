## Use case

The password reset functionality was vulnerable due to improper validation of the reset token against the username, allowing an attacker to reset any user's password without knowing their token. This flaw could lead to account takeover.

## Steps to test

1. Navigate to the login page and click 'Forgot password?'.
2. Submit a password reset request for your own account (e.g., wiener).
3. Intercept the request in Burp Suite Proxy / Repeater.
4. Open the link sent to your email client to access the password reset submission form.
5. Enter a new password (e.g., peter) and submit the form while monitoring the HTTP traffic in Burp Suite.
6. Locate the POST /forgot-password?temp-forgot-password-token=... request in Burp HTTP History and send it to Repeater.
7. Modify the request by emptying the temp-forgot-password-token parameter and setting username=carlos.
8. Send the modified request in Repeater and verify the password update succeeded.
