## Use case

The password reset flow was vulnerable due to a flaw that allowed bypassing authentication, which could lead to unauthorized access to user accounts. This is critical for protecting sensitive financial information.

## Steps to test

1. Navigate to the login page of the target application.
2. Click on the 'Forgot Password' link.
3. Enter a valid email address associated with an account.
4. Intercept the reset link sent to the email using a tool like Burp Suite.
5. Modify the reset link parameters if necessary to test for bypass.
6. Access the modified reset link to reset the password without proper authorization.
