## Use case

Weak username policies can lead to account enumeration, allowing attackers to predict valid usernames and potentially exploit authentication mechanisms. This vulnerability matters because it can expose user accounts without needing access to the application’s database.

## Steps to test

1. Identify the username format used by the application (e.g., firstname.lastname).
2. Generate a list of possible usernames based on the identified format.
3. Attempt to log in using a known username and a random password to check for response differences.
4. Test the registration and password reset functionalities with the generated usernames to see if the application confirms their existence.
5. Analyze the responses for differences in messages, HTTP status codes, and response lengths.
