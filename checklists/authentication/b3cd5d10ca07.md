## Use case

The vulnerability allows an attacker to bypass session revalidation and perform sensitive actions on a victim's account even if the victim denies the request through the mobile app. This is critical as it can lead to unauthorized account modifications.

## Steps to test

1. Attempt to add a phone number or email address on the victim's LinkedIn account.
2. Intercept the request using a proxy tool.
3. Wait for the victim to receive the mobile app prompt and deny the request.
4. Intercept the POST request sent by the victim's mobile app response.
5. Modify the intercepted response endpoint from '/checkpoint/challengesV2/inapp/paused/...?' to '/psettings/phone/add?challengeId='.
6. Forward the modified request to elevate privileges and access the phone number addition page.
