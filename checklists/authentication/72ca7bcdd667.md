## Use case

The vulnerability allowed an attacker to forge a session token for a user if they knew the user's UUID and that the user had an active session. This was critical as it enabled unauthorized access to user account information without needing to compromise credentials.

## Steps to test

1. Obtain a target user's non-enumerable UUID.
2. Confirm that there is an active session for the target user on the server.
3. Forge an HS256 token using the public RSA key as the HMAC secret.
4. Send the forged token to a v1 read endpoint to retrieve account data.

## Commands

```text
curl -X GET 'https://connect.8x8.com/v1/read-endpoint' -H 'Authorization: Bearer <forged_token>'
```
