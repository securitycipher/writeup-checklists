## Use case

The login page of Magadh University's website was vulnerable due to improper validation of user credentials, allowing unauthorized access to sensitive information. This vulnerability exposed personal data of thousands of students, making it critical to address.

## Steps to test

1. Navigate to the login page of Magadh University's website.
2. Enter an arbitrary username and password.
3. Observe if access is granted without proper validation.
4. Attempt to access sensitive information after logging in.

## Commands

```text
POST /login HTTP/1.1
Host: example.com
Content-Type: application/x-www-form-urlencoded
username=invalidUser&password=invalidPass
```
