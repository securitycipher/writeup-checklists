## Use case

The 2FA implementation was vulnerable due to flawed logic, allowing an attacker to bypass the authentication process by manipulating the verify cookie and mfa-code parameter.

## Steps to test

1. Log in with valid username and password to initiate the 2FA process.
2. Intercept the request to the /login2 endpoint using Burp Suite and note the verify cookie.
3. Send the request to the repeater and observe the 4-digit security code request.
4. Change the verify cookie value to the target user's username (e.g., 'carlos') and send the request to the /login2 endpoint with the mfa-code parameter.
5. Use Intruder to brute-force the mfa-code with a character set of '0123456789' and a length of 4.
6. Check for a 302 status code response indicating successful authentication.

## Commands

```text
POST /login2 HTTP/1.1
Host: example.com
Cookie: verify=carlos
mfa-code=1234
Intruder attack setup: Change verify cookie to 'carlos' and set mfa-code payload position.
```
