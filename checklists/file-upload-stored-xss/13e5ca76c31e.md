## Use case

The application allowed unauthenticated users to upload files, specifically SVG images, which could be served directly by a CDN without proper content-type validation, leading to stored XSS vulnerabilities.

## Steps to test

1. Obtain a CSRF token by sending a GET request to /api/auth/csrf.
2. Initiate the upload by sending a POST request to /api/trpc/public.imageUpload.initiateUpload?batch=1 with the CSRF token in the header.
3. Capture the presigned AWS S3 upload URL from the response.
4. Upload a malicious SVG file using the presigned URL with Content-Type set to image/svg+xml.
5. Access the uploaded SVG via the provided CloudFront URL.
6. Observe the JavaScript execution in the browser.
