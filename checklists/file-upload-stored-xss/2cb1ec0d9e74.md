## Use case

The application allowed users to upload custom avatars, which led to a remote code execution vulnerability due to improper handling of the uploaded files.

## Steps to test

1. Navigate to the user settings and find the 'Upload Custom Avatar' feature.
2. Prepare a malicious SVG file that contains XSS payload.
3. Use Burp Suite to intercept the request when uploading the avatar.
4. Modify the request to ensure the file type is accepted and the payload is executed.
5. Send the modified request to the server.
6. Observe the response and check if the payload executes in the context of the application.
