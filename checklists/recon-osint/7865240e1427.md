## Use case

The article discusses a method to discover historical files that may no longer be accessible through the current application, which can reveal sensitive information that was previously public. This matters because it can expose vulnerabilities related to information disclosure.

## Steps to test

1. Use the Wayback Machine's CDX API to collect historical URLs for the target domain.
2. Filter the collected URLs for interesting file extensions using grep.
3. Check the discovered URLs for 403 or 404 responses.
4. For 404 responses, verify if the URL was previously archived by entering it into the Wayback Machine and checking the timeline for archived versions.

## Commands

```text
curl -G 'https://web.archive.org/cdx/search/cdx' --data-urlencode 'url=*.example.com/*' --data-urlencode 'collapse=urlkey' --data-urlencode 'output=text' --data-urlencode 'fl=original' > out.txt
cat out.txt | uro | grep -E '\.xls|\.xml|\.xlsx|\.json|\.pdf|\.sql|\.doc|\.docx|\.pptx|\.txt|\.zip|\.tar\.gz|\.tgz|\.bak|\.7z|\.rar|\.log|\.cache|\.secret|\.db|\.backup|\.yml|\.gz|\.config|\.csv|\.yaml|\.md|\.md5|\.exe|\.dll|\.bin|\.ini|\.bat|\.sh|\.tar|\.deb|\.rpm|\.iso|\.img|\.apk|\.msi|\.dmg|\.tmp|\.crt|\.pem|\.key|\.pub|\.asc'
```
