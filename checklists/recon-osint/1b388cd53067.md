## Use case

The Ghost Engine v3.2 tool automates the reconnaissance phase of bug bounty hunting by identifying exposed subdomains, misconfigured security headers, and potential SSRF vulnerabilities through GraphQL introspection endpoints. This is crucial as it helps hunters uncover vulnerabilities that could lead to further exploitation.

## Steps to test

1. Clone the Ghost Engine repository using 'git clone https://github.com/ghostprotocolsha/ghost_engine.git'.
2. Navigate into the cloned directory with 'cd ghost_engine'.
3. Make the script executable by running 'chmod +x ghost_engine.py'.
4. Install the required dependencies using 'pip install requests'.
5. Run a complete surface scan against a target URL using 'python3 ghost_engine.py -u https://example.com'.
6. Enumerate subdomains and identify takeover risks with 'python3 ghost_engine.py -sub example.com'.
7. Brute-force directories using a custom wordlist with 'python3 ghost_engine.py -u https://example.com -w /path/to/wordlist.txt'.
