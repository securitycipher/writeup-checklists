## Use case

The article outlines a systematic approach to prioritize subdomains during bug bounty reconnaissance, which is crucial for identifying potential vulnerabilities efficiently. By focusing on high-priority subdomains, hunters can maximize their chances of finding exploitable issues.

## Steps to test

1. Define the authorized scope by creating a scope.txt file with the target domains.
2. Collect subdomains using subfinder and certificate transparency data.
3. Use HTTP probing with httpx to identify live hosts from the collected subdomains.
4. Extract interesting names from the subdomains using grep to find development or administrative patterns.
5. Prioritize the subdomains based on their environment and HTTP status codes.
