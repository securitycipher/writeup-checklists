## Use case

The application has multiple vulnerabilities including User-Agent bypass, directory listing exposure, and CVE vulnerabilities. These issues allow unauthorized access to sensitive information and potential exploitation of the server.

## Steps to test

1. Open the website in a desktop browser and note the redirection to /desktop.html.
2. Inspect the source code (Ctrl+U) to find the note.txt file reference.
3. Navigate to /note.txt and copy one of the iPhone User-Agents.
4. In Firefox, go to about:config, search for general.useragent.override, set it to the copied User-Agent, and reload the main page to see Flag 1.
5. Click on the 'Vulnerability Scanner' button to access /CVE-VULN/ and note the server software versions.
6. Search for CVEs affecting those versions and check them one by one to reveal Flag 3.
7. Navigate to /wp-includes/ to discover directory listing and find internal-notes.txt for Flag 2.
8. Access /wp-admin/config/passwds.html, decrypt the ROT13 passwords, and use them to gain root access via /wp-admin/shell/.

## Commands

```text
curl -A 'iPhone User-Agent' https://example.com/
curl https://example.com/note.txt
curl https://example.com/wp-includes/
curl https://example.com/wp-admin/config/passwds.html
```
