## Use case

Subdomain enumeration is essential for identifying potential vulnerabilities in web applications. By discovering subdomains associated with a target domain, hunters can uncover overlooked entry points for attackers.

## Steps to test

1. Use Sublist3r to enumerate subdomains by running 'sublist3r -d example.com'.
2. Run Amass to gather subdomains with 'amass enum -d example.com'.
3. Utilize crt.sh to search for certificates associated with the target domain by visiting 'https://crt.sh/?q=example.com'.
4. Perform a DNS zone transfer attempt using 'dnsrecon -d example.com -t axfr'.
5. Search for indexed subdomains using Google with the query 'site:example.com'.
6. Check for open S3 buckets using the command 'aws s3 ls s3://example-bucket-name' after configuring AWS CLI.
