## Use case

This article provides a methodology for using Nmap to identify open, closed, and filtered ports on a target, which is crucial for understanding the attack surface and potential vulnerabilities of a system.

## Steps to test

1. Ensure Nmap is installed by running 'nmap --version'.
2. If not installed, use 'sudo apt install nmap' for Debian/Ubuntu or 'sudo dnf install nmap' for Fedora/RHEL.
3. Scan a targeted list of well-known service ports using 'nmap -p 21,22,25,53,80,443,3306,6379 scanme.nmap.org'.
4. Run version detection on the open SSH port with 'nmap -sV -p 22 scanme.nmap.org'.
5. Search the version string for known vulnerabilities.

## Commands

```text

nmap -p 22,3306 scanme.nmap.org
nmap -Pn -p 22,80 scanme.nmap.org
```
