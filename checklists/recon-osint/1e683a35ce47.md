## Use case

The article discusses how to discover hidden paths and parameters in web applications, which can lead to potential vulnerabilities if these endpoints are not properly secured. Understanding these hidden elements is crucial for identifying attack surfaces that may be exploited.

## Steps to test

1. Use a subdomain enumeration tool to identify all subdomains of the target application.
2. Run ffuf with a wordlist to guess potential hidden paths, replacing FUZZ with common directory names.
3. Utilize Dirsearch to discover hidden directories and files, specifying common file extensions.
4. Employ Arjun or ParamSpider to identify hidden parameters by fuzzing common parameter names against known endpoints.

## Commands

```text
ffuf -u https://example.com/FUZZ -w /path/to/wordlist.txt
dirsearch -u https://example.com -e php,html,js
arjun -u https://example.com/api/v1/resource -p param1,param2,param3
paramspider -u https://example.com
ffuf — Look for paths by guessing
ffuf can use a wordlist to replace FUZZ with different words and check which paths respond.
```
