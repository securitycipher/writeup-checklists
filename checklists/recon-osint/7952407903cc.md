## Use case

IIS servers can expose sensitive information through short file names and specific headers. Identifying these can lead to further exploitation or information disclosure.

## Steps to test

1. Use Shodan to search for IIS instances with specific characteristics using the query: 'http.title:"IIS"'.
2. Run Nmap with the command 'nmap -p80 --script http-iis-short-name-brute <target_ip>' to enumerate short file names.
3. Utilize ffuf with the command 'ffuf -w iis.txt -u https://example.com/FUZZ' to brute force potential file paths.
4. Check for specific headers like 'X-AspNet-Version' and 'X-Powered-By' in the response to gather version information.

## Commands

```text
shodan search 'http.title:"IIS"'
nmap -p80 --script http-iis-short-name-brute <target_ip>
ffuf -w iis.txt -u https://example.com/FUZZ
```
