## Use case

The article provides a comprehensive workflow for conducting authorized bug bounty and security testing, focusing on reconnaissance techniques to identify potential vulnerabilities in web applications. This methodology is crucial for building an accurate attack surface inventory and prioritizing targets for further testing.

## Steps to test

1. Define the scope by identifying in-scope root domains and subdomains.
2. Perform passive reconnaissance using WHOIS and search engine queries to gather information about the target.
3. Use tools like Amass and Subfinder for subdomain enumeration and combine results.
4. Resolve DNS records and perform HTTP discovery using httpx to identify live hosts.

## Commands

```text
mkdir -p recon/{scope,subdomains,dns,hosts,ports,http,urls,content,params,tech,js,history,reports}
echo 'example.com' > scope/domains.txt
whois example.com
subfinder -d example.com -all -recursive -o subdomains/subfinder.txt
httpx -l dns/resolved.txt -silent -o http/live.txt
mkdir -p recon/{scope,subdomains,dns,hosts,ports,http,urls,content,params,tech,js,history,reports}
cd recon
echo "example.com" > scope/domains.txt
site:example.com
site:*.example.com
site:example.com login
site:example.com api
site:example.com admin
site:example.com dev
site:example.com staging
site:example.com filetype:pdf
site:example.com filetype:json
site:example.com filetype:xml
curl -s "https://crt.sh/?q=%25.example.com&output=json"
curl -s "https://crt.sh/?q=%25.example.com&output=json" \
| jq -r '.[].name_value' \
| sed 's/\*\.//g' \
| sort -u \
> subdomains/cert.txt
```
