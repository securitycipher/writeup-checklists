## Use case

The article outlines a structured recon workflow that transforms raw data into actionable targets for security testing. This approach is crucial for hunters to efficiently identify and prioritize vulnerabilities in a target's attack surface.

## Steps to test

1. Use 'subfinder' to enumerate subdomains of the target domain.
2. Run 'amass' to gather additional subdomain information.
3. Execute 'httpx' to identify which subdomains are alive and responsive.
4. Use 'nuclei' to scan the responsive subdomains for known vulnerabilities.
5. Analyze the output to create a shortlist of targets with hypotheses for testing.

## Commands

```text
subfinder -d example.com
amass enum -d example.com
httpx -l alive_subdomains.txt
nuclei -l responsive_subdomains.txt
subfinder on the root domain. amass for good measure. httpx to check what's alive. nuclei on everything that responded. Save the output. Move to the next programme.
```
