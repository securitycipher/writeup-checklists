## Use case

Ghost Engine v3.2 automates reconnaissance tasks such as subdomain enumeration, WAF detection, and SSL/TLS inspection, which are critical for understanding the attack surface of a target application. This tool helps identify potentially vulnerable endpoints and misconfigurations that could be exploited during a security assessment.

## Steps to test

1. Clone the Ghost Engine repository using 'git clone https://github.com/ghostprotocolsha/ghost_engine.git'.
2. Navigate into the directory with 'cd ghost_engine'.
3. Make the script executable using 'chmod +x ghost_engine.py'.
4. Install the required Python dependencies with 'pip install requests'.
5. Run a basic scan on a target domain using 'python3 ghost_engine.py -u https://example.com'.
6. Perform subdomain enumeration with 'python3 ghost_engine.py -sub example.com'.
