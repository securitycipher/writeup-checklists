## Use case

The vulnerability involved finding an unacclaimed AWS S3 bucket linked in a GitHub repository. This is significant as it can lead to unauthorized access to sensitive data stored in the bucket.

## Steps to test

1. Identify the target company and their GitHub repositories.
2. Use GitHub search dorks to find potential S3 bucket links: 'org:companyname s3://' and 'org:companyname s3.amazonaws.com'.
3. Review the search results for any unacclaimed S3 bucket links.
4. Check the permissions of the found S3 bucket to see if it is publicly accessible.

## Commands

```text
org:companyname s3://
org:companyname s3.amazonaws.com
I used the following dorks on github:
org:companyname s3://
org:companyname s3.amazonaws.com
```
