## Use case

The vulnerability allows any authenticated user to escalate their privileges by modifying role-related fields in requests, which can lead to unauthorized access and control over sensitive functionalities within the application.

## Steps to test

1. Authenticate as a standard user and capture the profile update request using Burp Suite.
2. Modify the 'assignedRoleNames' field in the request body from ['Customer'] to ['Admin'].
3. Send the modified request to the server.
4. Observe the server response for a successful role change.
5. Access admin functionalities to verify privilege escalation.
