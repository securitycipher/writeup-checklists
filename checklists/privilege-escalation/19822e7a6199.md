## Use case

The vulnerability allowed an unauthenticated user to gain access to the admin panel by exploiting a prototype pollution bug in the lodash library, which led to unauthorized access to sensitive administrative functions.

## Steps to test

1. Use OWASP ZAP to crawl the application and identify the JavaScript files.
2. Open the browser's Developer Tools and inspect the JavaScript bundles, specifically looking for lodash.
3. Confirm the presence of lodash version 4.17.21, which is vulnerable to CVE-2021-23337.
4. In the console, execute 'Object.prototype.isAdmin = true;' to manipulate the global object prototype.
5. Navigate to the /admin route and observe if the admin dashboard loads without authentication.
6. Optionally, intercept fetch requests and modify responses to always return admin payloads.

## Commands

```text
Object.prototype.isAdmin = true;
window.location.assign = function() {}; // to prevent redirection
```
