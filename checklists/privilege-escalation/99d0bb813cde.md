## Use case

Low-privilege users are able to create feature bundles in the Examtegg platform, which should be restricted to authorized personnel only. This vulnerability can lead to unauthorized access and manipulation of critical system configurations.

## Steps to test

1. Log in as a low-privilege user on the Examtegg platform.
2. Navigate to the feature bundle creation page.
3. Attempt to create a new feature bundle by filling out the required fields.
4. Submit the form and observe if the bundle is created successfully despite low privileges.

## Commands

```text
POST https://example.com/api/feature-bundles
Headers: { 'Authorization': 'Bearer <low_privilege_token>', 'Content-Type': 'application/json' }
Body: { 'name': 'Unauthorized Bundle', 'features': ['feature1', 'feature2'] }
```
