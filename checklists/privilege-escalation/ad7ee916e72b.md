## Use case

The vulnerability arises from the outdated version of polkit (0.96) that allows for privilege escalation through the exploitation of pkexec. This misconfiguration enables an attacker to gain root access by leveraging a crafted gconv module.

## Steps to test

1. Enumerate SUID binaries on the target system using 'find / -perm -4000 -type f 2>/dev/null'.
2. Identify the version of polkit using 'pkexec --version'.
3. If the version is below 0.120, prepare a gconv module using only ancient GLIBC symbols.
4. Compile the gconv module with '-shared -fPIC'.
5. Set the GCONV_PATH to the directory containing the gconv module and execute the launcher to gain root access.

## Commands

find / -perm -4000 -type f 2>/dev/null
pkexec --version
