## Use case

The application allows privilege escalation through token manipulation and localStorage abuse, enabling unauthorized access to admin-level features and sensitive information.

## Steps to test

1. Open the application in a web browser and access the main page.
2. Use DevTools (F12) to inspect the source code and find hidden flags.
3. Access the admin balance endpoint using the discovered admin token: api/balance/token_asdfdfghmqweiopanmqwe/
4. Access the users endpoint with the same admin token: api/users/token_asdfdfghmqweiopanmqwe/
5. Manipulate localStorage to set the casino token: localStorage.setItem('casino_token', 'asdfdfghmqweiopanmqwe');
6. Attempt a withdrawal using the correct confirmation flag after setting the token.
