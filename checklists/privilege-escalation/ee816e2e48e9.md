## Use case

After gaining access to a target system via exploitation, a penetration tester can escalate privileges to gain higher access levels. This is crucial for accessing sensitive data or performing further actions that require elevated permissions.

## Steps to test

1. Establish a Meterpreter session on the target system.
2. Run the command 'getsystem' to attempt automatic privilege escalation.
3. Use 'getprivs' to check current privileges.
4. If necessary, use 'steal_token PID' to steal a process token from a higher-privileged process.
5. Drop the stolen token using 'drop_token' and revert to the original token with 'rev2self' if needed.

getsystem
