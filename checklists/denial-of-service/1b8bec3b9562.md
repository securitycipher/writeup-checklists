## Use case

The API endpoint was accessible without proper authentication, allowing unauthenticated users to send repeated requests, which could lead to resource exhaustion and increased backend costs.

## Steps to test

1. Identify an API endpoint that is supposed to be protected (e.g., /api/auth/login).
2. Send a GET request to the API endpoint without authentication.
3. Observe the response headers for Cache-Control and Cf-Cache-Status.
4. Check for the absence of rate-limit headers in the response.
5. Use a tool like PLOW to send a high volume of requests to the API endpoint.
6. Measure the response time to confirm degradation under load.

## Commands

```text
GET /api/auth/login HTTP/2
plow https://dev.xxx.com/api/test -c 50 -d 60s -H 'Accept: application/json'
for i in {1..100}; do time curl -X GET 'https://dev.xxx.com/api/test$i' -H 'Accept: application/json' -s -o /dev/null -w 'Request $i: %{time_total}s
'; done
```
