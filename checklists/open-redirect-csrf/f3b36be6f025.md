## Use case

The application was vulnerable to CSRF attacks due to the absence of CSRF tokens in GraphQL API requests, allowing unauthorized CRUD operations on user profiles. This misconfiguration could lead to significant data manipulation without user consent.

## Steps to test

1. Identify a GraphQL mutation endpoint that performs a sensitive action, such as updating user profile information.
2. Capture a valid request to this mutation using Burp Suite.
3. Modify the Content-Type header from 'application/json' to 'application/x-www-form-urlencoded'.
4. Transform the JSON body into the application/x-www-form-urlencoded format.
5. Change the HTTP method from POST to GET to bypass CSRF protections.
6. Create a CSRF PoC HTML file that triggers the modified request when opened in an authenticated session.
