## Use case

The application allowed users to set usernames that bypassed frontend validation, enabling the storage of attacker-controlled URLs. This could lead to phishing attacks when other users visit the profile containing the malicious URL.

## Steps to test

1. Navigate to the profile page and enter a valid username.
2. Intercept the request using Burp Suite.
3. Modify the username parameter to a malicious URL, e.g., username=https://evil.com.
4. Forward the modified request.
5. Access the profile from another account to observe the redirection to the attacker-controlled URL.
