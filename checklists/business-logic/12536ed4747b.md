## Use case

The application allowed an authenticated low-privileged user to bypass package-scope authorization by exploiting the differing interpretations of duplicate JSON properties in the manifest, which led to unauthorized access to protected reports.

## Steps to test

1. Register for the application to receive a private package namespace.
2. Create a package manifest with two top-level package properties, one for your namespace and one for the protected package.
3. Base64-encode the raw manifest to preserve the duplicate keys.
4. Submit the encoded manifest to POST /api/manifests/sign and capture the approval ID.
5. Use the same manifest and approval bundle to POST /api/publications.
6. Retrieve the publication using GET /api/publications/{publication_id}.

## Commands
