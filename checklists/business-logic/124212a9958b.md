## Use case

The vulnerability exists in the invitation acceptance process where a revoked invitation can still be used to gain unauthorized access to an organization. This allows attackers to bypass the owner's revocation decision and potentially access sensitive organization resources.

## Steps to test

1. Create an organization as the victim.
2. Invite the attacker to join the organization.
3. Have the attacker accept the invitation and capture the request using Burp Repeater.
4. The victim revokes the invitation.
5. The attacker replays the captured invitation acceptance request from Burp Repeater.
6. Confirm that the attacker is granted access to the organization despite the revocation.

## Commands

```text
POST /accept-invitation HTTP/1.1
Host: example.com
Authorization: Bearer <token>
Content-Type: application/json
Body: {"invitationId": "<captured_invitation_id>"}
```
