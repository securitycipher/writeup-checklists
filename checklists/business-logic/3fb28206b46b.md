## Use case

The vulnerability allowed unauthenticated users to submit reviews on PriceRunner, undermining the integrity of the 'Verified Reviews' system, which was supposed to ensure that only verified customers could leave reviews.

## Steps to test

1. Use a proxy to monitor requests while browsing PriceRunner.
2. Identify the API endpoint for submitting reviews: POST /public/ccreview.
3. Send a POST request to /public/ccreview without authentication and with a JSON body containing 'authorEmail', 'merchantId', and 'scores'.
4. Observe the response to confirm that the request is processed without authentication.
5. Check for the presence of a review by querying the relevant merchant's score endpoint: GET /public/ccreview/{merchantId}/score.
6. Verify that the review has been accepted and persisted.
