## Use case

The application allowed users on lower subscription tiers to access premium features by manipulating API requests, which could lead to unauthorized access to sensitive functionalities.

## Steps to test

1. Inspect the client-side JavaScript for the integrations page to identify API endpoints.
2. Locate the endpoint for retrieving available integration platforms and note the platform IDs.
3. Find the endpoint responsible for updating restaurant integrations (UpdateRestaurantPlatforms).
4. Modify the request to include the Google Integration platform ID in the platformIds array and send it to the server.
5. Observe the server's response to confirm that the premium feature is enabled despite the user's subscription tier.

## Commands

```text
GET https://example.com/api/integrations
POST https://example.com/api/UpdateRestaurantPlatforms -d '{"platformIds": ["<GoogleIntegrationPlatformID>"]}'
```
