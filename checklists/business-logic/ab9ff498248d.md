## Use case

The application allowed users to redeem more reward points than they possessed, leading to the generation of unauthorized monetary credits. This flaw had a direct financial impact on users and the application, affecting hundreds of thousands of accounts.

## Steps to test

1. Identify the rewards redemption endpoint in the Salesforce Aura application.
2. Capture a valid request for redeeming reward points using a tool like Burp Suite.
3. Modify the request to include a redemption amount that exceeds the available reward points balance.
4. Send the modified request and observe the response for any monetary credit issued.
5. Check the account balance to confirm if it falls into the negative.

## Commands

```text
POST /redeem_rewards HTTP/1.1
Host: example.com
Content-Type: application/json
Authorization: Bearer <token>
{ "userId": "<user_id>", "redeemAmount": <excess_amount> }
```
