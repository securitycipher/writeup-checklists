## Use case

The vulnerability allowed an attacker to generate a report for a package in a namespace they did not own by exploiting the JSON parsing behavior of the application, which led to unauthorized access to sensitive information.

## Steps to test

1. Register an account to obtain your own private scope.
2. Use the Manifest Studio to create a manifest with a duplicate package object, one with your scope and one with the target scope.
3. Send the manifest to the /manifests/preview endpoint using a POST request.
4. If the response is valid, proceed to sign the manifest using the /manifests/sign endpoint.
5. Publish the signed manifest using the /publications endpoint.
6. Retrieve the report for the unauthorized package using the appropriate GET request.
