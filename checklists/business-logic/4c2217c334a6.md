## Use case

The vulnerability allowed an attacker to bypass CAPTCHA verification on a contact form, which could lead to automated spam or phishing attacks. This was significant as it disrupted the intended rate-limiting and security measures in place.

## Steps to test

1. Navigate to the contact form at https://www.example.com/en/contact-us.
2. Use Burp Suite to intercept the POST request when submitting the form.
3. Identify the parameters 'captcha_response' and 'captcha_token' in the request payload.
4. Manipulate the 'captcha_token' parameter to an invalid value and forward the request.
5. Observe the server response to confirm if it accepts the payload despite the invalid token.

## Commands

```text
POST /en/contact-us HTTP/1.1
Host: www.example.com
Content-Type: application/x-www-form-urlencoded
captcha_response=valid_response&captcha_token=invalid_token&other_field=value
```
