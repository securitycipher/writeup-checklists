## Use case

The vulnerability allowed an admin who is not the host to silently record meetings without notifying other participants, violating user consent on a privacy-focused platform.

## Steps to test

1. Log in as an admin user who is not the host of a Proton Meet session.
2. Start a meeting and ensure that the recording feature is enabled.
3. Observe that the recording UI does not display any indication of recording to other participants.
4. Verify that the recording is still taking place without consent notifications being shown.

## Commands

```text
if (!senderParticipant?.IsAdmin && !senderParticipant?.IsHost) { return; }
```
