## Use case

The application improperly sets directory permissions to 0777, allowing local users to tamper with application state, which can lead to integrity issues. This misconfiguration can be exploited in shared environments where umask settings are permissive.

## Steps to test

1. Set the umask to 000 using 'umask 000'.
2. Remove the existing state database directory.
3. Execute the application workflow that recreates the state.
4. Run 'ls -ld <state-directory>' to inspect the permissions of the state directory.

## Commands

```text
umask 000
rm -rf <state-directory>
ls -ld <state-directory>
```
