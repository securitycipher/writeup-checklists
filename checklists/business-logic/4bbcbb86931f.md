## Use case

The AI Assistant feature allowed users to access premium functionality without a valid subscription by manipulating client-controlled parameters in requests, which could lead to unauthorized access to features intended for paying users.

## Steps to test

1. Create a free account on the task management platform.
2. Navigate to the settings page and enable the AI Assistant feature.
3. Intercept the request to the AI Assistant using Burp Suite.
4. Modify the JSON parameter 'isPro' from false to true.
5. Forward the modified request and observe the response.
6. Verify access to AI suggestions as if you had a Pro subscription.
7. Review the API documentation for the AI Assistant feature.
8. Craft a request using the documented parameters to bypass the normal UI workflow.

## Commands

```text
POST /ai/assistant HTTP/1.1
Content-Type: application/json
{ 'isPro': true }
POST /ai/assistant/action HTTP/1.1
{ 'actionType': 'submit', 'actionId': 'Action.Suggest', 'inputs': { 'TextInput.Suggest': 'write whatever you want' } }

"isPro": true
"actionType": "initial"
"actionType": "submit"

}
}
```
