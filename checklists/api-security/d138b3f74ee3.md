## Use case

JavaScript files can expose sensitive API endpoints and authentication mechanisms that may lead to unauthorized access if not properly secured. Identifying these vulnerabilities is crucial for ensuring the application's security posture.

## Steps to test

1. Inspect the HTML source of the target application to identify JavaScript files.
2. Use browser Developer Tools to reload the application and interact with different features to load all JavaScript chunks.
3. Run 'curl -s https://target.example/ | grep -oE 'src="[^"]+\.js[^"]*"' to collect JavaScript URLs.
4. Search for API endpoints in the downloaded JavaScript files using 'grep -RniE '/api/|graphql|/v[0-9]+/' js/'.
5. Analyze the authentication and authorization controls of discovered endpoints to check for misconfigurations.
6. Look for sensitive information such as tokens or credentials in the JavaScript files.
