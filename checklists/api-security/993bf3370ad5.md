## Use case

CVE-2023–35078 is a critical vulnerability in Ivanti Endpoint Manager Mobile allowing unauthorized remote access to restricted server APIs. This vulnerability matters because it poses significant security risks to organizations using affected versions.

## Steps to test

1. Use Shodan to search for devices running MobileIron software with the filters 'http.favicon.hash:362091310' and 'http.favicon.hash:545827989'.
2. Access the identified device webpages and use the 'View Source' option to review the HTML code.
3. Locate the line containing 'mifs/css/ui.login.css?' to verify the software version is 11.9 or lower.
4. Download and customize the 'CVE-2023–35078-Exploit POC' script from GitHub to target the identified versions.
5. Execute the script and confirm successful operation by checking for the automatic download of a JSON file.
