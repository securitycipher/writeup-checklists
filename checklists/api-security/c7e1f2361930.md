## Use case

The vulnerability was found in an API endpoint that exposed sensitive user information, including phone numbers and financial data related to campaigns. This could lead to privacy violations and financial exploitation.

## Steps to test

1. Identify the target API endpoint for campaigns, e.g., GET /backend/v1/user/campaigns/{{campaign_id}}.
2. Log in to the application and create an account if necessary.
3. Enroll in a campaign to generate a valid campaign ID.
4. Capture the API request using Burp Suite while accessing the campaign details.
5. Analyze the response for sensitive information, including user phone numbers and financial data.
