## Use case

An unsecured API endpoint allowed unauthenticated access to sensitive BIN data, which could be exploited for fraud and phishing attacks.

## Steps to test

1. Identify the target mobile application and its API endpoints.
2. Monitor the API calls made by the application during the checkout process.
3. Send a GET request to the endpoint with a valid six-digit BIN, e.g., GET https://pay-api.example.com/v1/cardbins/432143.
4. Observe the response for sensitive information such as bank name, country, and card type.
5. Iterate through known BIN ranges to enumerate valid BINs using a script or tool.
