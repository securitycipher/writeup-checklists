## Use case

An exposed API endpoint allowed unauthorized access, enabling attackers to trigger actions that resulted in a financial loss of $10,000. This vulnerability highlights the critical need for proper authentication and access controls on APIs.

## Steps to test

1. Identify all publicly accessible APIs in the target application.
2. Check for authentication requirements on each API endpoint.
3. Attempt to access the exposed API endpoint without authentication.
4. Send a request to the endpoint to trigger an action (e.g., creating a shipment or processing a payment).
5. Verify if the action is executed successfully without proper authorization.
