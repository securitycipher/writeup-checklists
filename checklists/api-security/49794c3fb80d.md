## Use case

The vulnerability existed in an API endpoint that allowed participants of a collaborative board to access sensitive information about other participants without proper authorization checks, leading to the exposure of PII for over 100,000 users.

## Steps to test

1. Create or join a collaborative board on target.com.
2. Identify the board UUID from the URL or API response.
3. Send a GET request to /manager/api/brainstorms/{board-uuid}/participants without any authentication.
4. Observe the response containing PII of all participants on the board.
