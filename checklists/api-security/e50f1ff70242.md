## Use case

APIs often have vulnerabilities related to authentication and authorization. Exploiting these vulnerabilities can lead to unauthorized access to sensitive data or actions.

## Steps to test

1. Identify the API endpoint responsible for user authentication, e.g., POST /api/login.
2. Capture the request using a proxy tool and note the parameters sent, such as 'username' and 'password'.
3. Modify the 'username' parameter to test for user enumeration, e.g., use a valid username and an invalid password.
4. Attempt to bypass authentication by manipulating the 'password' parameter with common passwords or SQL injection payloads.
5. Check for error messages that may reveal information about valid usernames or account status.

## Commands

```text
POST https://example.com/api/login
Content-Type: application/json
Body: {"username": "testuser", "password": "wrongpassword"}
GET https://example.com/api/userinfo
Authorization: Bearer <token>
```
