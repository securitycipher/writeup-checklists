## Use case

The application allowed API access to be obtained using only the victim's email, bypassing normal authentication flows including 2FA, which led to a campaign takeover. This was significant as it demonstrated how multiple weaknesses could be exploited in sequence to achieve a high-impact outcome.

## Steps to test

1. Identify a subdomain related to the API that accepts victim email for access.
2. Send a request to the API with the victim's email to obtain API access.
3. Use the victim's username and password to request an API token without 2FA.
4. Access the campaign invitation endpoint using the obtained API token.
5. Send an invitation to your own account as OWNER.
6. Accept the invitation and remove the legitimate user from the campaign.

## Commands
