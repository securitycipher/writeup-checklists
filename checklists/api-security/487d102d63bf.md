## Use case

The exposed eXist-db REST interface allowed unauthenticated access to sensitive application resources, including database collections and configuration files, which could lead to significant information disclosure and potential exploitation.

## Steps to test

1. Identify the eXist-db REST endpoint, e.g., /exist/rest/db/
2. Send a GET request to the endpoint without authentication.
3. Observe the response for exposed database collections and application resources.
4. Test the query functionality by sending a request with an XQuery expression parameter, e.g., /exist/rest/db/?query=your_xquery_here.

## Commands

```text
GET http://example.com/exist/rest/db/
GET http://example.com/exist/rest/db/?query=for $x in collection('your_collection') return $x
/exist/rest/db/
```
