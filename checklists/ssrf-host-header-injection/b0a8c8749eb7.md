## Use case

The application exposes a Server-Side Request Forgery (SSRF) vulnerability through the stock check feature, allowing attackers to access internal services. This vulnerability can be exploited to manipulate internal routing and potentially access sensitive administrative functions.

## Steps to test

1. Log in to the application with valid credentials.
2. Identify the stock check feature and note the request format: POST /product/stock with stockApi parameter.
3. Use Burp Intruder to brute-force the last octet of the internal IP range (192.168.0.[x]:8080) by sending GET /admin requests with the Host header set to 192.168.0.[discovered_IP]:8080.
4. Once the correct internal IP is found, attempt to access the admin panel using the identified IP and issue a GET request to /admin.
5. If successful, locate the user management table and delete the user 'carlos' using the appropriate action.
