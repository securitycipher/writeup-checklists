## Use case

The Swisstronik wallet extension was found to log plaintext mnemonics to Sentry during user signup and mnemonic import. This is critical as it exposes sensitive user information that could be exploited if an attacker gains access to the logs.

## Steps to test

1. Create a new account on the Swisstronik wallet extension and monitor the network requests.
2. Check for any outgoing requests to Sentry during the signup process.
3. Import a mnemonic into the wallet and again monitor the network requests.
4. Verify if the plaintext mnemonic is included in the logs sent to Sentry.

## Commands

```text
curl -X POST 'https://wallet.swisstronik.com/api/signup' -H 'Content-Type: application/json' -d '{"username":"testuser","password":"testpass","mnemonic":"example mnemonic here"}'
curl -X POST 'https://wallet.swisstronik.com/api/import' -H 'Content-Type: application/json' -d '{"mnemonic":"example mnemonic here"}'
```
