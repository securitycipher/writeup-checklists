## Use case

The 'Preview' button in the document management system allowed unauthorized access to private documents due to predictable identifiers in the API call, leading to exposure of sensitive information.

## Steps to test

1. Intercept the request made when clicking the 'Preview' button using Burp Suite.
2. Identify the API endpoint and the 'doc_id' parameter in the intercepted request.
3. Modify the 'doc_id' parameter to a different document ID that you suspect may exist.
4. Send the modified request and observe the response for any unauthorized document access.

## Commands

```text
GET /api/v2/documents/preview?doc_id=DOC-XXXXXXX-PDF
GET /api/v2/documents/preview?doc_id=DOC-883921-PDF
```
