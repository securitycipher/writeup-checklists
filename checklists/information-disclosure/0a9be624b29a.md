## Use case

The IIS tilde enumeration vulnerability allows unauthorized users to access sensitive files and directories by manipulating URLs. This can lead to exposure of confidential information that should not be publicly accessible.

## Steps to test

1. Set up Burp Suite and configure it to intercept requests.
2. Send an OPTIONS request to the target URL to identify valid endpoints.
3. Manipulate the URL by appending '~1\a.aspx?&aspxerrorpath=/' to the valid endpoint.
4. Observe the response status codes; valid paths should return 403 errors while manipulated paths may return 200 statuses.
5. Use Burp Intruder to automate the enumeration of short filenames by sending requests with variations of the tilde character.

## Commands

```text
OPTIONS http://example.com/path HTTP/1.1
GET http://example.com/path/~1\a.aspx?&aspxerrorpath=/ HTTP/1.1
```
