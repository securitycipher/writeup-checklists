## Use case

The vulnerability involved a cloud storage bucket that was unintentionally left public, allowing unauthorized access to file listings and metadata. This exposure can lead to reconnaissance opportunities for attackers.

## Steps to test

1. Identify a staging environment of a web application.
2. Browse to a subdomain of the application.
3. Look for responses that return XML documents instead of HTML.
4. Check if the XML document contains a storage bucket listing.
5. Analyze the object names, upload timestamps, file sizes, and metadata for any sensitive information.

## Commands

```text
GET https://example.com/path/to/storage/bucket
curl -X GET https://example.com/path/to/storage/bucket
```
