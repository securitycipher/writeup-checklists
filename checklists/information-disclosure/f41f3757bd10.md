## Use case

The Heartbleed vulnerability allows an unauthenticated attacker to exploit a flaw in OpenSSL's TLS heartbeat implementation, leading to the disclosure of sensitive information from server memory.

## Steps to test

1. Set up a vulnerable OpenSSL service in an isolated environment using Docker.
2. Check the OpenSSL version with 'openssl version' to ensure it is within the vulnerable range (1.0.1 to 1.0.1f).
3. Start Metasploit with 'msfconsole'.
4. Use the Heartbleed scanner with 'use auxiliary/scanner/ssl/openssl_heartbleed'.
5. Set the target with 'set RHOSTS 127.0.0.1' and 'set RPORT 443'.
6. Run the scanner with 'run' to check for vulnerability.
