## Use case

The vulnerability involved the exposure of job applicant emails through archived pages on the Wayback Machine, which could be exploited for phishing and social engineering attacks.

## Steps to test

1. Perform a Wayback Machine CDX query using the endpoint: https://web.archive.org/cdx/search/cdx?url=*.[REDACTED]/*&collapse=urlkey&output=text&fl=original.
2. Identify URLs that follow the pattern /mysql/?view_responses=<identifier>.
3. Access the archived snapshots of these URLs to check for exposed data.
4. Count the number of archived pages and estimate the number of exposed emails based on the number of applicants per page.

## Commands

```text
https://web.archive.org/cdx/search/cdx?url=*.[REDACTED]/*&collapse=urlkey&output=text&fl=original
http://www.[REDACTED]:80/mysql/?view_responses=<identifier>
1,114 × 40 = 44,560
```
