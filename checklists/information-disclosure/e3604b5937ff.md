## Use case

The vulnerability occurred when a staff member's session cookie was inadvertently pasted into a public report, allowing an attacker to replay the cookie and gain unauthorized access to staff-level privileges.

## Steps to test

1. Access the bug bounty program's disclosed reports on HackerOne.
2. Search for reports related to account takeover.
3. Identify any reports that contain session cookies in their body.
4. Copy the session cookie from the report.
5. Use the copied session cookie in a new request to the application, ensuring to set the Cookie header appropriately.
6. Observe if access is granted to staff-level functionalities.

## Commands

```text
curl -X GET https://example.com/some/protected/endpoint -H 'Cookie: session_cookie_value'
```
