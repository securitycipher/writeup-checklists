## Use case

The application exposed sensitive user information through unauthenticated API queries, allowing attackers to retrieve private data without authentication. This vulnerability could lead to privacy breaches and targeted attacks against users.

## Steps to test

1. Send a POST request to /api/query with the following JSON payload: { 'path': 'users:getUserByUsername', 'format': 'json', 'args': { 'username': '<target username>' } }
2. Observe the response for sensitive fields such as email, IP address, and subscription status.
3. Send a request to /api/query with the following JSON payload: { 'path': 'users:searchPeople', 'format': 'json', 'args': { 'searchQuery': 'a', 'limit': 32 } }
4. Analyze the response to enumerate usernames and identify privileged accounts.
