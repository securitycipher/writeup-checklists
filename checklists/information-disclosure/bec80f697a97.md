## Use case

The NewPath WildApricotPress Add-on for WordPress had a vulnerability that allowed unauthenticated users to access sensitive member information via the REST API. This exposure could lead to phishing attacks and unauthorized profiling.

## Steps to test

1. Identify a WordPress site using the NewPath WildApricotPress Add-on Member Directory plugin version 1.0.0 or lower.
2. Access the REST API endpoint at '/wp-json/newpath-wap/v1/directory'.
3. Send a GET request to the endpoint without authentication.
4. Check the response for exposed member records, including emails and phone numbers.
