## Use case

The Coldcard hardware wallet firmware misconfiguration led to predictable seed generation, allowing attackers to reconstruct private keys from public information, which resulted in the theft of over $130 million in Bitcoin.

## Steps to test

1. Identify Coldcard wallets by checking for unique IDs exposed through USB serial numbers.
2. Gather public wallet addresses from the blockchain to find dormant wallets with large balances.
3. Use the unique ID and approximate timer values to generate candidate seeds using the flawed RNG.
4. Derive corresponding Bitcoin addresses and check against the public blockchain addresses to find matches.
