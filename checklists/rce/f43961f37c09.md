## Use case

Server-side template injection (SSTI) vulnerabilities can occur in features that allow user input to be concatenated into template strings, such as email customization or profile bios. This can lead to remote code execution if the input is evaluated by the template engine.

## Steps to test

1. Identify a feature that allows user input to be rendered in a template, such as a profile bio or email template.
2. Input the universal probe command {{7*7}} into the field.
3. Submit the form and observe the output.
4. If the output is 49, SSTI is confirmed. If the output is {{7*7}}, the input was not evaluated.

## Commands

```text
{{7*7}}
${7*7}
<%= 7*7 %>
#{7*7}
{{7*7}}
${7*7}
<%= 7*7 %>
#{7*7}
```
