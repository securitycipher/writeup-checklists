## Use case

The vulnerability was in Bing's public-facing 'Search by Image' upload tool, which allowed an SVG file to execute OS commands due to improper handling of user-uploaded images, leading to full SYSTEM-level access on Microsoft servers.

## Steps to test

1. Navigate to the Bing Images 'Search by Image' upload tool.
2. Create an SVG file that contains a pipe-prefixed command to be executed.
3. Upload the crafted SVG file through the image upload feature.
4. Monitor the server response to confirm command execution.
5. Verify access by checking for SYSTEM-level access on the server.

## Commands

```text
curl -X POST -F 'image=@malicious.svg' https://www.bing.com/images/search
```
