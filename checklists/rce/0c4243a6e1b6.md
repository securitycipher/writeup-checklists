## Use case

The vulnerability was found in a file upload feature where the server incorrectly handled MIME type validation, allowing the upload of a PHP file that could be executed remotely. This misconfiguration led to remote code execution on the server.

## Steps to test

1. Identify a file upload feature on the target application.
2. Attempt to upload a PHP file directly and confirm it is blocked.
3. Try uploading a file with a double extension (e.g., rev.php.jpg) and confirm it is rejected.
4. Use null byte injection in the filename (e.g., rev.php%00.jpg) and confirm it is rejected.
5. Submit a multipart form with two filename parameters: filename="rev.php%00"; filename="rev.php%00.gif".
6. Set the Content-Type to application/pdf and submit the form.
