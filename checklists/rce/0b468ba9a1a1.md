## Use case

The vulnerability exists in a Smarty template where user input is processed without proper validation, allowing for server-side template injection (SSTI) that can lead to remote code execution. This is critical as it can allow an attacker to execute arbitrary commands on the server.

## Steps to test

1. Identify a user input field that processes Smarty templates.
2. Inject the payload '{system('ls')}' and observe the response.
3. If blocked by regex, modify the payload to include a URL-encoded new line: '{system('ls')%0a}'.
4. Use Burp Suite to intercept the request and modify the parameter to include the new payload.
5. Send the request and check the server response for execution results.
