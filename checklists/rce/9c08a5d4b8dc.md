## Use case

The application had a parameter called 'filename' that appeared to be vulnerable to remote command execution, as it showed signs of processing input without returning any errors. This could lead to unauthorized command execution if exploited.

## Steps to test

1. Identify the parameter 'filename' in the application that processes input.
2. Send various payloads to the 'filename' parameter and observe the response.
3. If no output is returned, set up an out-of-band (OOB) listener to catch callbacks.
4. If OOB fails, attempt to write a file to a web-accessible path and retrieve it to confirm execution.
