## Use case

The application allowed organization administrators to customize email notifications, which led to a Server-Side Template Injection vulnerability. This vulnerability allowed an attacker to execute arbitrary code on the server, resulting in a complete server takeover.

## Steps to test

1. Access the email template builder as an organization administrator.
2. Insert a payload into the template, such as {{config}} to test for SSTI.
3. Save the template and trigger the email notification to execute the payload.
4. Observe the response to determine if the payload executed successfully.

## Commands

```text
POST /api/send-email HTTP/1.1
Host: example.com
Content-Type: application/json
Authorization: Bearer YOUR_ACCESS_TOKEN
{"template":"{{config}}"}
```
