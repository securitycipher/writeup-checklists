## Use case

The vulnerability was found in the file upload feature of a Joomla site, where the server relied on the browser's MIME type for validation instead of checking the file extension server-side. This allowed an attacker to upload a PHP file disguised as a PDF, leading to remote code execution.

## Steps to test

1. Identify a file upload feature on the target site (e.g., employment application form).
2. Craft a PHP file and set the MIME type to application/pdf.
3. Use curl to send a POST request to the upload endpoint with the crafted file.
4. Access the uploaded file via the web server to execute the PHP code.

## Commands

```text
curl -X POST -F 'file=@/path/to/malicious.php;type=application/pdf' http://example.com/images/artforms/attachedfiles/upload
```
