## Use case

The article discusses a header injection vulnerability that can lead to remote code execution, highlighting its potential impact when exploited in a critical environment like GitHub. It emphasizes that what may seem like a low-impact finding can have severe consequences.

## Steps to test

1. Send a request to the target application with a crafted header that includes a '\r\n' sequence to inject a new header.
2. Alternatively, include a semicolon ';' in a header value to create a second key-value pair.
3. Observe the response to confirm that the injected header is reflected back.
4. Assess the application for any further vulnerabilities that could be exploited using the injected header.

## Commands

```text
curl -H 'X-Custom-Header: value\r\nInjected-Header: injected_value' http://example.com
curl -H 'X-Custom-Header: value; Injected-Header: injected_value' http://example.com
```
