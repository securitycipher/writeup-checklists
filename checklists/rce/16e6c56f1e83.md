## Use case

The Everest Toolkit WordPress plugin allowed authenticated users to upload files without proper validation, enabling the execution of arbitrary PHP code on the server. This vulnerability is critical as it can lead to full server compromise.

## Steps to test

1. Log in to the WordPress admin panel with Admin+ privileges.
2. Navigate to the file import feature of the Everest Toolkit plugin.
3. Prepare a malicious PHP file for upload (e.g., a file named 'malicious.php' containing PHP code).
4. Upload the malicious file using the import feature.
5. Access the uploaded file via the web server to execute the PHP code (e.g., http://example.com/wp-content/uploads/malicious.php?cmd=your_command).
