## Use case

The vulnerability was found in a contact form where user input was processed by PHP, allowing for code injection that could lead to remote code execution. This mattered because it could allow an attacker to execute arbitrary commands on the server.

## Steps to test

1. Use Burp Suite to intercept the request to the contact form.
2. Inject the PHP opening tag '<?php' into the input field and submit the form.
3. Observe the server response for a 500 Internal Server Error, indicating PHP processing.
4. Inject the payload '<?php system('ls');die;?>' into the input field and submit.
5. Check the response for the output of the 'ls' command to confirm code execution.
6. Optionally, upload a web shell by transferring a PHP file and accessing it via the browser.
