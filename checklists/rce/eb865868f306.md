## Use case

The vulnerability exists in a desktop application that allows file synchronization without user acceptance of collaboration invitations, enabling an attacker to deliver malicious files to a victim's computer. This is critical as it bypasses user consent and can lead to remote code execution if the victim opens the malicious file.

## Steps to test

1. Create a folder in the application.
2. Upload a malicious file (e.g., accounts.bat) using the API: POST /api/2.0/files/content with appropriate form-data.
3. Add the victim's email as a collaborator on the folder.
4. Ensure the victim does not accept the collaboration invitation.
5. Observe that the desktop application synchronizes the folder and the malicious file appears on the victim's computer.
6. Have the victim open the malicious file to execute the commands.
