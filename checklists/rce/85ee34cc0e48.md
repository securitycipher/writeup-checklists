## Use case

The application had debug mode enabled in production, which exposed sensitive information about the file system and allowed for file uploads to a publicly accessible location, potentially leading to remote code execution if the uploaded files were executed by the server.

## Steps to test

1. Access the application and confirm that debug mode is enabled by triggering an error to view the debug page.
2. Note the BASE_DIR value displayed on the debug page.
3. Check if the application allows file uploads and identify the upload functionality.
4. Upload a file with weak validation to the identified upload endpoint.
5. Verify where the uploaded file is stored and if it is publicly accessible.
6. Access the uploaded file via the web server to determine if it can be executed.

## Commands

```text
GET /path/to/upload/endpoint HTTP/1.1
POST /path/to/upload/endpoint HTTP/1.1
Content-Disposition: form-data; name="file"; filename="malicious.php"
GET /uploaded/malicious.php HTTP/1.1
BASE_DIR : /home/user/app_dir
https://site.com:2083
```
